# PRD-06: 数据导入导出

## 1. 功能概述

数据导入导出模块涵盖三大功能：CSV/文本文件导入（含服务器端和客户端两种解析模式）、CSV 格式自动检测与建表、表复制（结构+数据跨数据库）。该模块支持灵活的字段分隔符/包围符配置、编码检测、重复行处理、WHERE 过滤等功能。

### 1.1 相关源码

| 文件 | 大小 | 职责 |
|------|------|------|
| `loaddata.pas` | 26KB | CSV/文本文件导入（服务端 LOAD DATA + 客户端解析） |
| `csv_detector.pas` | 13KB | CSV 文件格式检测与自动建表 |
| `copytable.pas` | 18KB | 表复制（结构+数据，跨数据库） |
| `insertfiles.pas` | 23KB | 批量文件内容插入（BLOB 导入） |

## 4. 功能详细说明

### 4.1 CSV/文本文件导入 (loaddata.pas)

#### 4.1.1 文件选择

- 支持 CSV (`.csv`)、文本 (`.txt`) 和任意文件
- 打开文件时选择编码（Auto detect/ANSI/ASCII/Unicode/UTF-8/UTF-7 等）
- 自动检测编码失败时显示警告并提示手动选择
- 文件路径和编码选择持久化保存

#### 4.1.2 目标选择

- 数据库下拉：列出当前连接的所有数据库，默认选中当前活动数据库
- 表下拉：列出所选数据库的所有表和视图，默认选中当前活动表
- 表列表末尾添加 `<New table>` 选项，点击后弹出 CSV 检测器自动建表
- 列选择列表：显示目标表的所有列，带复选框控制导入映射

#### 4.1.3 列映射

- 复选列表显示目标表所有列
- 默认全选（`CheckAll(cbChecked)`）
- 上移/下移按钮调整列的映射顺序
- 全选/取消全选按钮（图标根据状态切换）
- 文件中的列按顺序映射到勾选的目标列

#### 4.1.4 字符设置

| 设置项 | 说明 | 默认值 |
|--------|------|--------|
| 字段分隔符 | 字段之间的分隔字符 | `,` |
| 字段包围符 | 包围字段内容的字符 | `"` |
| 转义字符 | 转义特殊字符的前缀 | `\` |
| 行终止符 | 行结束标记 | `\r\n` |
| 包围符可选 | 包围符是否可选（OPTIONALLY ENCLOSED） | 否 |

#### 4.1.5 导入选项

| 选项 | 说明 | MySQL 专属 |
|------|------|------------|
| 忽略行数 | 跳过文件开头的 N 行（通常为表头） | 否 |
| 低优先级 | LOW_PRIORITY 延迟写入 | 是 |
| 本地化数字 | 处理千分位分隔符和本地小数点 | 否 |
| 导入前清空表 | TRUNCATE TABLE（失败时回退到 DELETE FROM） | 否 |
| 保持对话框打开 | 导入完成后不关闭对话框，方便连续导入 | 否 |

#### 4.1.6 重复处理（MySQL 专属）

| 模式 | SQL 关键字 | 说明 |
|------|------------|------|
| 默认 | INSERT | 遇到重复键报错 |
| 忽略 | INSERT IGNORE | 跳过重复行 |
| 替换 | REPLACE | 替换已存在的行 |

#### 4.1.7 解析方式

**服务端解析 (LOAD DATA)**（MySQL 专属）：
- 生成 `LOAD DATA LOCAL INFILE` 语句
- 支持 `CHARACTER SET` 指定文件编码
- 文件名自动转换为 8.3 短格式（避免 MySQL 库路径问题）
- 支持 `SET @ColVar` 语法处理本地化数字转换

**客户端解析 (INSERT)**：
- 客户端逐字符解析文件内容
- 生成批量 `INSERT INTO ... VALUES (...), (...), ...` 语句
- 自动分包（每包 ≤ 0.5MB 或达到 `MaxRowsPerInsert` 行）
- 执行前临时设置 `SQL_MODE=''`（MySQL），完成后恢复
- 数值类型列自动 `UnformatNumber`
- 缺失值自动填充 NULL

#### 4.1.8 导入执行流程

1. 若勾选"清空表"，执行 `TRUNCATE TABLE`（失败回退 `DELETE FROM`）
2. 根据解析方式调用 `ServerParse` 或 `ClientParse`
3. 显示进度条（100 步）和行计数状态
4. 完成后记录导入行数和耗时到日志
5. 0 行导入时弹出错误提示（可能原因：空文件/编码错误/分隔符不匹配）

### 4.2 CSV 格式检测器 (csv_detector.pas)

#### 4.2.1 检测流程

1. 读取文件前 20MB 内容
2. 按用户指定的分隔符/包围符/行终止符逐字符解析
3. 将解析结果存入 `TGridRows` 内存结构
4. 分析每列的数据类型和长度

#### 4.2.2 数据类型检测

| 检测类型 | 判断规则 |
|----------|----------|
| Integer | `StrToInt64Def` 成功且值与原文一致 |
| Float | 包含小数点且所有字符为 `0-9.` |
| Date | 正则 `^\d{4}-\d{2}-\d{2}$` |
| DateTime | 正则 `^\d{4}-\d{2}-\d{2}\s\d{2}:\d{2}:\d{2}$` |
| Text | 以上均不匹配 |

#### 4.2.3 列名确定

- 若 `IgnoreLines > 0`：使用第一行值作为列名（经过 `CleanIdent` 清理）
- 否则：自动生成列名 `col_0`, `col_1`, ...

#### 4.2.4 类型选择策略

- 遍历所有行的值，逐步提升列的数据类型（Integer → Float → Text）
- 根据最大值/长度选择合适的子类型（如 TINYINT/INT/BIGINT、VARCHAR/TEXT/LONGTEXT）
- NULL 或空值检测：`'NULL'`、`'\N'`、空字符串 → 设置 `AllowNull = True`

#### 4.2.5 输出

- 生成 `CREATE TABLE` SQL 显示在 SynMemo 中（带语法高亮）
- 用户可编辑后点击"保存为新表"执行建表
- 建表成功后刷新导入对话框的表列表

### 4.3 表复制 (copytable.pas)

#### 4.3.1 复制选项树

| 节点 | 子节点 | 说明 |
|------|--------|------|
| Columns | 各列名（带复选框） | 选择要复制的列 |
| Indexes | 各索引名（带复选框） | 选择要复制的索引 |
| Foreign keys | 各外键名（带复选框） | 选择要复制的外键 |
| Data | 无子节点 | 是否复制数据（显示行数） |

- 三态复选框：全选/全不选/部分选中
- 禁用条件：无子项或数据行数为 0 时禁用
- 选项状态持久化保存

#### 4.3.2 WHERE 过滤

- SynMemo 编辑器，支持 SQL WHERE 子句（不含 WHERE 关键字）
- 仅在勾选 Data 时启用，带 SQL 语法高亮
- 最近过滤条件保存（最多 20 条），通过下拉菜单快速选择

#### 4.3.3 执行流程

1. 检查目标表是否已存在，若存在弹出覆盖确认（DROP + 重建）
2. 生成 `CREATE TABLE` 语句：
   - 选中的列定义
   - 选中的索引定义
   - 选中的外键定义
   - 表选项（COLLATE/ENGINE/ROW_FORMAT/AUTO_INCREMENT/COMMENT）
3. 处理自增列：若自增列的索引未被选中，自动移除 AUTO_INCREMENT 属性
4. 排除虚拟列（Virtuality 非空）不参与 INSERT
5. 若勾选 Data，生成 `INSERT INTO new_table (cols) SELECT cols FROM old_table [WHERE ...]`
6. 执行查询，刷新数据库对象树并选中新表

### 4.4 批量文件插入 (insertfiles.pas)

- 将文件内容作为 BLOB 插入到数据库
- 支持多文件批量选择
- 文件路径、文件名等元数据可作为列值

## 5. 业务规则与约束

| ID | 规则 | 说明 |
|----|------|------|
| BR-6.1 | 文件存在验证 | 导入按钮仅当文件存在且列已加载时启用 |
| BR-6.2 | 表名非空 | 复制对话框中目标表名不能为空 |
| BR-6.3 | 自增列保护 | 复制表时若未选中自增列关联的索引，自动移除 AUTO_INCREMENT |
| BR-6.4 | 目标表覆盖 | 复制时若目标表已存在，需用户确认后先 DROP 再 CREATE |
| BR-6.5 | MySQL 专属功能 | 服务端解析、IGNORE/REPLACE、LOW_PRIORITY 仅在 MySQL 连接时可用 |
| BR-6.6 | 客户端解析 SQL_MODE | MySQL 客户端解析前临时设置 `SQL_MODE=''` 以避免严格模式错误 |
| BR-6.7 | 清空表回退 | TRUNCATE TABLE 失败时回退到 DELETE FROM |
| BR-6.8 | 导入分包 | 客户端解析每批 ≤ 0.5MB 或 MaxRowsPerInsert 行，避免超大数据包 |
| BR-6.9 | 文件编码 | 服务端解析使用 CHARACTER SET 指定编码；客户端解析在 Delphi 层面处理编码 |
| BR-6.10 | 虚拟列排除 | 复制表时虚拟列 (Virtuality 非空) 不参与 INSERT..SELECT |

## 7. 边界情况

| 场景 | 处理方式 |
|------|----------|
| 空文件 | 0 行导入时弹出错误提示，列出可能原因 |
| 编码选择错误 | 可能导致乱码或导入失败，客户端解析依赖 Delphi 编码转换 |
| 文件列数 > 表列数 | 多出的列值被忽略 |
| 文件列数 < 表列数 | 缺失的列填充 NULL |
| 包围符内的分隔符 | 正确识别为字段内容（InEncl 状态机） |
| 多字符分隔符 | 支持（TestLeftChars 逐字符匹配） |
| CSV 检测器 - 超大文件 | 仅读取前 20MB 进行分析 |
| CSV 检测器 - 类型不一致 | 逐步提升类型（Integer → Float → Text），确保兼容所有值 |
| 复制表 - 空表 | Data 节点被禁用（vsDisabled） |
| 复制表 - 自增列无索引 | 自动移除 AUTO_INCREMENT，错误时提示需选中关联索引 |
| 文件名含长路径 | 服务端解析自动转换为 8.3 短格式路径 |
| 网络断开 | 导入过程中连接断开时捕获 EDbError 并显示错误 |
