## 📋 文档维护

### 文档更新流程

1. 修改文档
2. 提交 PR
3. 团队成员审查
4. 合并到 main 分支

### 文档规范

- 使用 Markdown 格式
- 文件命名：使用中文或英文均可，但需保持一致
- 目录结构：按照分类组织
- 更新日志：在文档末尾记录更新信息

### 文档检查清单

创建或更新文档时，请确保：

- [ ] 内容准确、完整
- [ ] 代码示例可运行
- [ ] 格式正确（使用 Markdown lint）
- [ ] 链接有效
- [ ] 添加了目录（如需要）
- [ ] 记录了版本和更新日期
