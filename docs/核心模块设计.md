# ReidiSQL 核心模块设计

## 1. 数据库连接模块 (dbconnection.pas)

### 1.1 模块概述

数据库连接模块是整个应用的核心，提供了与各种数据库系统通信的抽象层。该模块定义了统一的接口，使得上层应用可以使用相同的方式操作不同的数据库系统。

### 1.2 核心类设计

#### 1.2.1 TDBConnection（抽象基类）

**职责**：
- 管理数据库连接生命周期
- 执行 SQL 查询
- 提供数据库元数据
- 管理事务

**主要属性**：
```pascal
property NetType: TNetType;           // 网络类型
property ServerVersion: Integer;      // 服务器版本
property Database: String;            // 当前数据库
property Connected: Boolean;          // 连接状态
property Queries: TDBQueryList;       // 查询列表
```

**主要方法**：
```pascal
procedure Connect; virtual; abstract;          // 连接数据库
procedure Disconnect; virtual; abstract;       // 断开连接
function GetTableColumns(...): TTableColumnList; virtual; // 获取表列
procedure GetDatabaseObjects(...); virtual;    // 获取数据库对象
function Execute(...): TDBQuery; virtual;      // 执行查询
procedure StartTransaction; virtual;           // 开始事务
procedure Commit; virtual;                     // 提交事务
procedure Rollback; virtual;                   // 回滚事务
```

#### 1.2.2 TDBQuery

**职责**：
- 封装查询执行
- 管理结果集
- 处理查询参数

**主要属性**：
```pascal
property SQL: String;               // SQL 语句
property Eof: Boolean;              // 是否到末尾
property RecordCount: Integer;      // 记录数
property FieldCount: Integer;       // 字段数
property Fields[Index: Integer]: TField; // 字段
```

**主要方法**：
```pascal
procedure Open;                     // 打开查询
procedure Close;                    // 关闭查询
procedure Next;                     // 下一条记录
procedure First;                    // 第一条记录
function FieldByName(Name: String): TField; // 按名称获取字段
```

#### 1.2.3 TDBObject

**职责**：
- 表示数据库对象（表、视图、存储过程等）
- 存储对象元数据
- 提供对象操作方法

**主要属性**：
```pascal
property Name: String;              // 对象名称
property Schema: String;            // 模式
property Database: String;          // 数据库
property NodeType: TListNodeType;   // 节点类型
property CreateCode: String;        // 创建语句
```

**主要方法**：
```pascal
procedure Drop;                     // 删除对象
procedure UnloadDetails;            // 卸载详细信息
function QuotedName: String;        // 引用名称
```

### 1.3 表结构相关类

#### 1.3.1 TTableColumn

**职责**：表示表的一列

```pascal
TTableColumn = class(TPersistent)
  Name, OldName: String;
  DataType, OldDataType: TDBDatatype;
  LengthSet: String;
  Unsigned, AllowNull, ZeroFill, Invisible: Boolean;
  DefaultType: TColumnDefaultType;
  DefaultText: String;
  Comment, Charset, Collation: String;
  SRID: Cardinal;
  Status: TEditingStatus;
  
  function SQLCode(...): String;      // 生成列定义 SQL
  function Serialize: String;         // 序列化
  procedure ParseDatatype(Source: String); // 解析数据类型
end;
```

#### 1.3.2 TTableKey

**职责**：表示表的索引

```pascal
TTableKey = class(TPersistent)
  const
    PRIMARY = 'PRIMARY';
    KEY = 'KEY';
    UNIQUE = 'UNIQUE';
    FULLTEXT = 'FULLTEXT';
    SPATIAL = 'SPATIAL';
    VECTOR = 'VECTOR';
    
  Name, OldName: String;
  IndexType, OldIndexType, Algorithm, Comment: String;
  Columns, SubParts, Collations: TStringList;
  Modified, Added, Visible: Boolean;
  
  function IsPrimary: Boolean;
  function IsIndex: Boolean;
  function IsUnique: Boolean;
  function SQLCode(TableName: String): String;
end;
```

#### 1.3.3 TForeignKey

**职责**：表示外键约束

```pascal
TForeignKey = class(TPersistent)
  KeyName, OldKeyName: String;
  Db, ReferenceDb, ReferenceTable: String;
  Columns, ForeignColumns: TStringList;
  OnUpdate, OnDelete: String;
  Modified, Added: Boolean;
  
  function SQLCode(IncludeSymbolName: Boolean): String;
  function ReferenceTableObj: TDBObject;
end;
```

## 2. 数据库结构模块 (dbstructures.pas)

### 2.1 模块概述

该模块定义了通用的数据库结构常量、数据类型、查询模板等。每个支持的数据库都有对应的 dbstructures.xxx.pas 文件，定义数据库特定的结构。

### 2.2 网络类型定义

```pascal
TNetType = (
  ntMySQL_TCPIP,
  ntMySQL_NamedPipe,
  ntMySQL_SSHtunnel,
  ntMSSQL_NamedPipe,
  ntMSSQL_TCPIP,
  ntPgSQL_TCPIP,
  ntPgSQL_SSHtunnel,
  ntSQLite,
  ntInterbase_TCPIP,
  ntInterbase_Local,
  ntFirebird_TCPIP,
  ntFirebird_Local,
  // ...
);
```

### 2.3 数据类型定义

#### 2.3.1 TDBDatatype

```pascal
TDBDatatype = record
  Index: TDBDatatypeIndex;        // 类型索引
  NativeType: Integer;             // 原生类型ID
  Name: String;                    // 类型名称
  HasLength: Boolean;              // 是否有长度属性
  RequiresLength: Boolean;         // 是否必需长度
  MaxSize: Int64;                  // 最大大小
  DefaultSize: Int64;              // 默认大小
  HasBinary: Boolean;              // 是否可以是二进制
  HasDefault: Boolean;             // 是否可以有默认值
  Category: TDBDatatypeCategoryIndex; // 类型分类
end;
```

#### 2.3.2 数据类型分类

```pascal
TDBDatatypeCategoryIndex = (
  dtcInteger,    // 整数
  dtcReal,       // 实数
  dtcText,       // 文本
  dtcBinary,     // 二进制
  dtcTemporal,   // 时间
  dtcSpatial,    // 空间
  dtcOther       // 其他
);
```

### 2.4 SQL 提供者 (TSqlProvider)

**职责**：提供数据库特定的 SQL 查询模板

```pascal
TSqlProvider = class
  function Has(AId: TQueryId): Boolean;
  function GetSql(AId: TQueryId): string; virtual;
  function GetSql(AId: TQueryId; const Args: array of const): string;
end;
```

**查询 ID 枚举**：
```pascal
TQueryId = (
  qDatabaseTable,
  qDatabaseDrop,
  qDbObjectsTable,
  qAddColumn,
  qChangeColumn,
  qForeignKeyDrop,
  // ... 更多查询ID
);
```

## 3. 主窗体模块 (main.pas)

### 3.1 模块概述

主窗体是应用的核心用户界面，整合了所有功能模块。它负责管理用户交互、协调各个子模块的工作。

### 3.2 查询标签页类 (TQueryTab)

**职责**：管理单个查询标签页的状态

```pascal
TQueryTab = class(TComponent)
  Number: Integer;
  Uid: String;
  MemoFilename: String;
  QueryRunning: Boolean;
  ExecutionThread: TQueryThread;
  Memo: TSynMemo;
  ResultTabs: TResultTabs;
  ListBindParams: TListBindParam;
  HistoryDays: TStringList;
  
  function GetActiveResultTab: TResultTab;
  procedure LoadContents(Filepath: String; ...): Boolean;
  procedure SaveContents(Filename: String; OnlySelection: Boolean);
  procedure BackupUnsavedContent;
  property ActiveResultTab: TResultTab;
end;
```

### 3.3 结果标签页类 (TResultTab)

**职责**：管理查询结果的展示

```pascal
TResultTab = class(TObject)
  Results: TDBQuery;
  Grid: TVirtualStringTree;
  FilterText: String;
  TabIndex: Integer;
end;
```

### 3.4 查询历史类 (TQueryHistory)

**职责**：管理查询历史记录

```pascal
TQueryHistoryItem = class(TObject)
  Time: TDateTime;
  Database: String;
  SQL: String;
  Duration: Cardinal;
end;

TQueryHistory = class(TObjectList<TQueryHistoryItem>)
  constructor Create(SessionPath: String);
end;
```

### 3.5 绑定参数类

```pascal
TBindParam = class(TObject)
  Name: String;
  Value: String;
  Keep: Boolean;
end;

TListBindParam = class(TObjectList<TBindParam>)
  property AsText: String read GetAsText write SetAsText;
  procedure CleanToKeep;
end;
```
