# ReidiSQL 开发指南

## 1. 开发环境设置

### 1.1 硬件要求

- 处理器：现代 x86/x64 处理器（Intel i5 或更高）
- 内存：至少 8 GB RAM（推荐 16 GB）
- 磁盘空间：至少 10 GB 可用空间

### 1.2 软件要求

#### 必需软件
- **操作系统**：Windows 10 或更高版本
- **Delphi**：Delphi 12.1 或 Delphi 12.3（Community Edition 也可）
- **madExcept**：用于错误报告（可选但推荐）

#### 可选软件
- Git：版本控制
- 文本编辑器：VS Code、Notepad++ 等

### 1.3 安装步骤

1. **安装 Delphi**
   - 下载并安装 Delphi 12.1/12.3
   - 确保安装了 VCL 组件
   - 安装时选择完整安装

2. **获取源代码**
   ```bash
   git clone <repository-url>
   cd ReidiSQL
   ```

3. **安装组件**
   - 项目包含第三方组件（SynEdit、VirtualTreeView）
   - 打开 `components/SynEdit/Packages/Delphi12.3/SynEdit.groupproj`
   - 编译并安装 SynEdit 设计时包
   - 对 VirtualTreeView 执行同样操作

4. **安装 madExcept**（可选）
   - 下载并安装 madExcept
   - 确保在 Delphi IDE 中正确配置

### 1.4 项目配置

打开项目文件：
- Delphi 12.1: `packages/Delphi12.1/heidisql.dproj`
- Delphi 12.3: `packages/Delphi12.3/heidisql.dproj`

## 2. 项目结构说明

### 2.1 目录结构

```
ReidiSQL/
├── components/              # 第三方组件
│   ├── synedit/           # SynEdit 代码编辑器
│   └── virtualtreeview/   # VirtualTreeView 控件
```

## 3. 编译和构建

### 3.1 编译资源

在编译主程序前，需要先编译资源文件：

```batch
# 运行资源构建脚本
build-res.bat
```

或者手动编译：
- 编译 `res/icon.rc`
- 编译 `res/icon-question.rc`
- 编译 `res/version.rc`
- 编译 `res/manifest.rc`
- 编译 `res/updater.rc`（64位）
- 编译 `res/styles.rc`
- 编译 `source/vcl-styles-utils/AwesomeFont.rc`

### 3.2 编译项目

在 Delphi IDE 中：
1. 打开项目文件
2. 选择目标平台（Win32 或 Win64）
3. 选择构建配置（Debug 或 Release）
4. 按 F9 或点击「运行」按钮

### 3.3 构建配置说明

| 配置 | 说明 |
|------|------|
| Debug | 调试版本，包含调试信息 |
| Release | 发布版本，优化代码 |

### 3.4 使用 build.php 构建

项目提供了 PHP 构建脚本：

```bash
php build.php
```

## 4. 调试技巧

### 4.1 madExcept 调试

项目集成了 madExcept，用于错误报告：
- 自动捕获未处理的异常
- 生成详细的错误报告

1. 在 `TDBConnection.Connect` 方法中设置断点

4. 查看错误信息

#### 调试 SQL 查询问题
1. 在 `TDBConnection.Execute` 方法中设置断点
2. 检查生成的 SQL 语句
3. 在数据库客户端中手动执行 SQL
4. 检查参数绑定

#### 调试界面问题
1. 使用 VCL 调试器检查控件属性
2. 检查事件处理程序
3. 验证数据绑定

### 4.3 日志输出

使用 `OutputDebugString` 或自定义日志输出调试信息。

## 5. 代码规范

### 5.1 命名约定

#### 类名
- 使用 PascalCase
- 前缀 `T`（如 `TMainForm`、`TDBConnection`）

#### 变量名
- 使用驼峰命名法（camelCase）
- 私有字段前缀 `F`（如 `FName`）
- 属性去掉 `F` 前缀（如 `Name`）

#### 方法名
- 使用 PascalCase
- 动词开头（如 `LoadData`、`SaveSettings`）

#### 常量名
- 使用全大写下划线分隔（如 `MAX_RETRY_COUNT`）
- 或 PascalCase（已有的代码风格）

#### 组件名
- 使用小写前缀
  - `btn` 按钮
  - `edt` 编辑框
  - `lbl` 标签
  - `pnl` 面板
  - `grd` 网格
  - `tv` 树形视图
  - `cb` 复选框
  - `rb` 单选按钮
  - `mmo` 备注/编辑器
  - `dlg` 对话框

### 5.2 代码格式

#### 缩进
- 使用 2 个空格或 1 个制表符
- 保持与现有代码一致

#### 对齐
- 等号对齐
- 注释对齐

#### 空行
- 方法之间空行
- 逻辑块之间空行

### 5.3 注释规范

#### 单元注释
每个单元文件开头应有简要说明：
```pascal
{
  单元名称: xxx.pas
  功能描述: ...
  作者: ...
  日期: ...
}
```

#### 类注释
```pascal
{
  类名: Txxx
  功能描述: ...
}
Txxx = class
end;
```

#### 方法注释
```pascal
{
  方法名: DoSomething
  功能描述: ...
  参数:
    Param1 - 说明
    Param2 - 说明
  返回值: 说明
}
procedure DoSomething(Param1: Integer; Param2: string);
```

#### 内联注释
使用 `//` 进行单行注释，解释复杂的代码逻辑。

### 5.4 异常处理

```pascal
try
  // 可能抛出异常的代码
except
  on E: Exception do
  begin
    // 记录日志
    LogError(E.Message);
    // 显示用户友好的错误信息
    ShowError(E.Message);
  end;
end;
```

### 5.5 资源释放

确保释放创建的对象：
```pascal
Obj := TObject.Create;
try
  // 使用 Obj
finally
  Obj.Free;
end;
```

或使用 `TObjectList` 管理对象生命周期。

## 6. 添加新功能

### 6.1 添加新对话框

1. 创建新的 Form 单元（.pas 和 .dfm）
2. 在 `heidisql.dpr` 中添加 uses 子句
3. 在主窗体中添加调用代码
4. 在菜单/工具栏添加按钮或菜单项

示例：
```pascal
// 在 main.pas 中添加
uses
  ..., MyNewDialog;

procedure TMainForm.btnMyNewDialogClick(Sender: TObject);
begin
  with TMyNewDialog.Create(nil) do
  try
    ShowModal;
  finally
    Free;
  end;
end;
```

### 6.2 添加新菜单项

1. 在主窗体设计器中添加菜单项
2. 设置 Caption 和 Name 属性
3. 连接 OnClick 事件处理程序
4. 如有需要，设置图标（ImageIndex）

### 6.3 添加新的数据库操作

1. 在 `TSqlProvider` 中添加新的查询模板
2. 在 `TDBConnection` 派生类中实现方法
3. 在主窗体或相关对话框中调用

### 6.4 添加新的数据类型支持

1. 在 `dbstructures.pas` 中的 `TDBDatatypeIndex` 枚举添加新类型
2. 在 `dbstructures.xxx.pas` 中添加数据库特定的类型映射
3. 在表编辑器中添加类型支持

## 7. 支持新的数据库系统

要添加对新数据库系统的支持，请按以下步骤：

### 7.1 创建结构定义文件

创建 `source/dbstructures.mydb.pas`：
```pascal
unit dbstructures.mydb;

interface

uses
  dbstructures;

procedure InitMyDBTypes(out Datatypes: array of TDBDatatype);

implementation

procedure InitMyDBTypes(out Datatypes: array of TDBDatatype);
begin
  // 初始化数据类型
end;

end.
```

### 7.2 创建连接类

创建 `source/mydbconnection.pas`：
```pascal
unit mydbconnection;

interface

uses
  dbconnection, dbstructures, ...;

type
  TMyDBConnection = class(TDBConnection)
  public
    constructor Create; override;
    destructor Destroy; override;
    procedure Connect; override;
    procedure Disconnect; override;
    // 重写其他必要方法
  end;

implementation

constructor TMyDBConnection.Create;
begin
  inherited;
  // 初始化
end;

procedure TMyDBConnection.Connect;
begin
  // 实现连接逻辑
end;

// 实现其他方法

end.
```

### 7.3 创建 SQL 提供者

创建继承自 `TSqlProvider` 的类，实现数据库特定的查询模板。

### 7.4 集成到连接管理器

在 `connections.pas` 和 `dbconnection.pas` 中添加新数据库的支持：
1. 在 `TNetType` 枚举添加新类型
2. 在连接对话框中添加新数据库选项
3. 在连接工厂中添加创建代码

## 8. 国际化 (i18n)

### 8.1 添加可翻译字符串

使用 `_()` 或 `gettext()` 标记可翻译字符串：
```pascal
Caption := _('Save');
ShowMessage(_('Are you sure?'));
```

### 8.2 更新翻译文件

项目使用 GNU Gettext 进行国际化：

1. 提取字符串到 .pot 文件
2. 更新 .po 文件
3. 编译 .mo 文件

使用 `extra/internationalization/` 目录下的工具。

### 8.3 添加新语言

1. 创建新的 .po 文件
2. 翻译字符串
3. 编译为 .mo
4. 在应用中注册新语言

## 12. 常见问题

### 12.1 编译错误

**问题**：找不到 SynEdit 或 VirtualTreeView
**解决**：确保已安装这些组件并在 IDE 中正确配置

**问题**：资源文件编译失败
**解决**：运行 build-res.bat 或手动编译 .rc 文件

### 12.2 运行时错误

**问题**：数据库连接失败
**解决**：
- 检查连接参数
- 检查网络连接
- 检查数据库服务是否运行
- 检查防火墙设置

**问题**：界面显示乱码
**解决**：
- 检查操作系统区域设置
- 检查应用语言设置
- 检查数据库字符集

### 12.3 调试问题

**问题**：断点不触发
**解决**：
- 确保使用 Debug 配置
- 清理并重新编译
- 检查调试器设置
