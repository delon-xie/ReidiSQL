# PRD-10: 偏好设置与系统配置

## 1. 功能概述

偏好设置模块是应用的全局配置中心，通过标签页式对话框管理所有用户可自定义选项。涵盖通用设置（语言/主题/字体）、SQL 日志配置、SQL 编辑器外观与行为、数据网格格式化、数据编辑器开关、快捷键自定义和文件/标签页行为。另含主题预览窗口，从服务器下载主题截图实时预览。

### 源码映射
| 源文件 | 行数 | 核心类 |
|--------|------|--------|
| `preferences.pas` | 1691 | TfrmPreferences |
| `theme_preview.pas` | 117 | TfrmThemePreview |

## 4. 功能详细说明

### 4.1 General 标签页

#### 4.1.1 多实例运行
| 控件 | 设置键 | 默认值 |
|------|--------|--------|
| `chkAllowMultiInstances` | `asAllowMultipleInstances` | `True` |

启用后允许同时运行多个应用实例。

#### 4.1.2 自动重连
| 控件 | 设置键 | 默认值 |
|------|--------|--------|
| `chkAutoReconnect` | `asAutoReconnect` | `False` |

启动时自动重连上次打开的会话。

#### 4.1.3 恢复上次数据库
| 控件 | 设置键 | 默认值 |
|------|--------|--------|
| `chkRestoreLastDB` | `asRestoreLastUsedDB` | `True` |

启动时自动选中上次使用的数据库。

#### 4.1.4 更新检查
| 控件 | 设置键 | 说明 |
|------|--------|------|
| `chkUpdatecheck` | `asUpdatecheck` | 总开关，控制子选项启用状态 |
| `editUpdatecheckInterval` | `asUpdatecheckInterval` | 检查间隔（天），0 = 每次启动 |
| `chkUpdatecheckBuilds` | `asUpdatecheckBuilds` | 同时检查 nightly builds |

- 关闭 `chkUpdatecheck` 时，间隔输入框和 builds 选项均禁用
- UpDown 范围：0–999

#### 4.1.5 使用统计
| 控件 | 设置键 | 说明 |
|------|--------|------|
| `chkDoStatistics` | `asDoUsageStatistics` | 每月 ping heidisql.com 上报版本 |

#### 4.1.6 Ctrl+滚轮缩放
| 控件 | 设置键 |
|------|--------|
| `chkWheelZoom` | `asWheelZoom` |

启用后在编辑器中 Ctrl+滚轮可缩放字体。

#### 4.1.7 列表柱状条
| 控件 | 设置键 |
|------|--------|
| `chkColorBars` | `asDisplayBars` |

在各种列表列中显示彩色柱状条（如表大小、进程时间等）。

#### 4.1.8 MySQL 命令行程序路径
| 控件 | 设置键 | 说明 |
|------|--------|------|
| `editMySQLBinaries` | `asMySQLBinaries` | mysqldump/mysql.exe 所在目录 |

- 带浏览按钮（RightButton），双击也可触发浏览
- **Wine 环境**：隐藏浏览按钮（返回 Unix 路径问题），同时禁用双击浏览
- 浏览对话框标题：`Find mysql.exe directory`
- 不显示"新建文件夹"按钮（`bifNoNewFolderButton`）

#### 4.1.9 自定义代码片段目录
| 控件 | 设置键 | 说明 |
|------|--------|------|
| `editCustomSnippetsDirectory` | `asCustomSnippetsDirectory` | SQL 代码片段文件目录 |

- 带浏览按钮，支持新建文件夹（`bifNewDialogStyle`）

#### 4.1.10 应用语言
| 控件 | 设置键 | 需重启 |
|------|--------|--------|
| `comboAppLanguage` | `asAppLanguage` | 是（Tag=1） |

- 第一项：`*** Auto detect ({系统语言})`，对应空字符串
- 后续项格式：`{代码}: {语言名}`，如 `de: German`、`zh_CN: Chinese (China)`
- 语言列表从 dxgettext 获取可用翻译，按字母排序
- 保存时通过正则 `^(\w+)\b` 提取语言代码

#### 4.1.11 GUI 字体
| 控件 | 设置键 | 需重启 |
|------|--------|--------|
| `comboGUIFont` | `asGUIFontName` | 是 |
| `editGUIFontSize` / `updownGUIFontSize` | `asGUIFontSize` | 是 |

- 第一项：`<Default system font>`，保存为空字符串
- 列出所有屏幕字体（排除 `@` 开头的竖排字体）
- 选择"默认"时字号控件禁用
- 字号范围：4+ pt

#### 4.1.12 样式主题
| 控件 | 设置键 | 需重启 |
|------|--------|--------|
| `comboTheme` | `asTheme` | 是 |

- 列出 `TStyleManager.StyleNames` 所有已注册 VCL 样式
- 按字母排序（Sorted=True）
- 标签附带 `(DEPRECATED)` 标记
- 切换主题时自动联动：
  - **暗色主题** → 网格颜色切 Dark，编辑器颜色切 Material
  - **亮色主题** → 网格颜色切 Light，编辑器颜色切 Light
- 勾选"Preview"时打开主题预览窗口

#### 4.1.13 图标包
| 控件 | 设置键 |
|------|--------|
| `comboIconPack` | `asIconPack` |

- 从 MainForm 上枚举所有 `TImageCollection` 组件
- 名称提取：去掉组件名中的 `ImageCollection` 后缀

#### 4.1.14 网页搜索基础 URL

#### 4.3.7 SQL 示例代码

SELECT DATE_SUB(NOW(), INTERVAL 1 DAY),

### 4.6 Shortcuts 标签页

#### 4.6.1 快捷键树
- 使用 `TVirtualStringTree` 懒加载
- **分类结构**：
  - Level 0：Action 分类（来自 `MainForm.ActionList1`）+ "SQL editing"
  - Level 1：具体 Action 或 SynMemo Keystroke
- **过滤**：`editShortcutsFilter` 实时过滤节点（`FilterNodesByEdit`），右侧 ✕ 按钮清空

#### 4.6.2 快捷键编辑
| 控件 | 说明 |
|------|------|
| `FHotKey1` | 主快捷键（TExtSynHotKey，动态创建） |
| `FHotKey2` | 次快捷键（仅 SQL editing 类别可用） |
| `btnRemoveHotKey1` / `btnRemoveHotKey2` | 清除快捷键按钮 |

- 选择 Action 类项目时，HotKey2 禁用（Action 仅支持一个快捷键）
- 选择 SQL editing 类项目时，两个快捷键均可编辑
- 标签显示 Action 描述（`ActionList1DefaultHints`）
- 编辑快捷键时禁用 OK 的 Default 和 Cancel 的 Cancel 属性（防止 Esc/Enter 干扰）

#### 4.6.3 快捷键冲突检测
`EnsureShortcutIsUnused` 方法：
1. 遍历所有快捷键节点
2. 发现冲突时弹出确认对话框：
   - **Yes**：解除冲突项的快捷键，分配给当前项
   - **No**：取消修改，恢复原快捷键
   - **Ignore**：保留两者，忽略后续所有冲突检查
3. 快捷键为 0（空）时跳过检测

#### 4.6.4 快捷键保存
- **Action 快捷键**：以 Action 名称为子键存入 `asActionShortcut1`
- **SynMemo 快捷键**：以 `EditorCommandToCodeString` 为子键存入 `asActionShortcut1/2`
- 保存后立即生效到当前会话的 Action

### 4.8 Restore Defaults 按钮

`btnRestoreDefaultsClick` 方法：
1. 弹出确认对话框（含说明文本）
2. 调用 `AppSettings.ResetPath` 重置注册表路径
3. 遍历删除所有已存储值
4. 重新执行 `FormShow` 刷新界面

### 4.9 Apply 与 Apply 后行为

Apply 按钮执行 `Apply` 方法：
1. 保存所有设置到 AppSettings（注册表）
2. 遍历快捷键树保存修改的快捷键
3. 调用 `MainForm.SetupSynEditors` 同步编辑器设置到所有实例
4. 刷新主窗口网格字体、图标列表、颜色
5. 禁用 Apply 按钮表示已保存
6. 如果修改了需重启的选项（Tag > 0），标记 `FRestartOptionApplied`

**关闭对话框时**：若 `FRestartOptionApplied = True`，弹出提示：
> "You should restart {APPNAME} to apply changed critical settings, and to prevent unexpected behaviour."

### 4.10 主题预览窗口 (TfrmThemePreview)

#### 4.10.1 功能说明
- 由 General 标签页的"Preview"复选框触发创建

#### 4.10.2 图片加载流程
```
LoadTheme(ThemeName)

  → 下载到临时文件: {TempDir}{APPNAME}-themepreview-{name}.png
  → 加载到 imagePreview
  → 状态栏显示主题名
  → 异常时状态栏显示错误信息
```

#### 4.10.3 交互

| Shift + 滚轮 | 水平滚动图片 |

## 5. 业务规则与约束

### 5.1 需重启生效的设置
带 `Tag = 1` 的控件修改后标记 `FRestartOptionTouched`：
- 应用语言（`comboAppLanguage`）
- GUI 字体（`comboGUIFont`、`editGUIFontSize`、`updownGUIFontSize`）
- 样式主题（`comboTheme`）

关闭窗口时提示重启。

### 5.2 标签页切换保护
- `pagecontrolMainChanging` 记录修改状态到 `FWasModified`
- `pagecontrolMainChange` 恢复修改状态
- 防止 TEdit+TUpDown 在标签切换时误触发 OnChange 启用 Apply 按钮

### 5.3 联动行为
| 触发 | 联动 |
|------|------|
| 关闭更新检查 | 禁用间隔输入和 builds 选项 |
| 关闭代码补全 | 禁用延迟和中间匹配选项 |
| 关闭日志文件 | 禁用目录输入 |
| 关闭查询历史 | 禁用保留天数 |
| 选择"默认系统字体" | 禁用字号控件 |
| 选择暗色主题 | 自动切换网格颜色和编辑器颜色为暗色方案 |
| 选择亮色主题 | 自动切换为亮色方案 |

### 5.4 快捷键编辑约束
- 打开偏好设置时全局 ActionList 暂停（`asSuspended`），关闭时恢复（`asNormal`）
- HotKey 控件设置 `InvalidKeys = []`，`Modifiers = []`（允许任意组合）
- 快捷键为 0 时不触发冲突检测
- Action 类仅支持快捷键 1，SQL editing 类支持两个快捷键

### 5.5 网格行数安全校验
`editGridRowCountExit`：行数为 0 或负数时自动修正为 1，防止数据网格出现问题。

### 5.6 颜色预设切换
- 网格颜色预设第一项（"当前自定义"）选中时不标记修改
- 编辑器颜色预设未找到匹配时回退到当前自定义设置

## 6. 快捷键

偏好设置窗口本身无特殊快捷键。通过 Shortcuts 标签页可自定义所有 Action 和 SQL 编辑器命令的快捷键。

## 7. 边界情况

| 场景 | 处理方式 |
|------|----------|
| Wine 环境 | MySQL 二进制路径浏览按钮隐藏（Unix/Windows 路径不兼容） |
| 所有字体均无 `@` 前缀 | 过滤竖排字体，仅保留常规字体 |
| 语言翻译缺失 | `InitLanguages` 中语言名返回空字符串 |
| 主题预览下载失败 | 状态栏显示异常消息，不弹窗 |
| 快捷键冲突选 Ignore | 跳过后续所有冲突检查，保留重复快捷键 |
| 行数为 0 或负数 | OnExit 事件自动修正为 1 |
| 恢复默认值 | 删除注册表所有值，重新加载 FormShow |
| 未安装任何 VCL 样式 | 主题下拉为空，默认值可能为 -1 |
