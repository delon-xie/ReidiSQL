# Sprint 5: 服务器管理 + UI 增强

## 现状分析

Sprints 1-4 已完成：连接管理、对象树、SQL 编辑器、查询执行、结果网格(含内联编辑)、表设计器、导入导出、视图/存储过程/触发器编辑器、用户管理、偏好设置、表工具、SQL 帮助、更新检查。

后端已有 `server-info` / `variables` / `processes` 三个端点但无前端 UI。

Sprint 5 补齐 6 个缺失模块。

---

## Task 1: 服务器管理后端补全

**修改** `node-backend/src/services/metadataService.ts`
- 新增 `setVariable(connectionId, name, value)` -- `SET GLOBAL name = value`
- 新增 `killProcess(connectionId, pid)` -- `KILL pid`
- 增强 `getServerInfo()` 返回 `SHOW GLOBAL STATUS` 统计（Threads_connected, Queries, Questions, Slow_queries, Bytes_received, Bytes_sent）

**新建** `node-backend/src/routes/server.ts` (~60 行)
- `GET /api/server/:connectionId/info` -- 服务器信息 + 统计
- `GET /api/server/:connectionId/variables` -- 变量列表 (支持 ?filter=)
- `PUT /api/server/:connectionId/variables/:name` -- SET 变量
- `GET /api/server/:connectionId/processes` -- 进程列表
- `POST /api/server/:connectionId/processes/:pid/kill` -- KILL 进程

**修改** `node-backend/src/index.ts` -- 注册 server 路由，版本号 `0.5.0-sprint5`

## Task 5: SQL 智能补全增强

**新建** `frontend/src/utils/sqlCompletion.ts` (~200 行)
- Monaco `CompletionItemProvider` 实现
- 数据源：从 objectTreeStore 获取当前数据库的表名、列名、视图名
- 补全类别：
  - SQL 关键字 (SELECT, INSERT, UPDATE, DELETE, CREATE, ALTER, DROP, ...)
  - 表名 (从对象树提取)
  - 列名 (当前 SQL 中 FROM 后的表的列)
  - 内置函数 (COUNT, SUM, AVG, NOW, CONCAT, ...)
- `registerCompletionProvider()` 注册函数，返回 disposable

**修改** `frontend/src/components/SQLEditor.tsx`
- 在 `handleEditorMount` 中调用 `registerCompletionProvider`
- 监听 objectTreeStore 变化更新补全数据源
