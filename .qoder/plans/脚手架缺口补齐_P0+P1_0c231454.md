## Task 2: 随机端口 + Token 认证 (P0 #2)

**修改** `node-backend/src/index.ts`
- 读取环境变量 `REIDISQL_PORT`（默认仍 3001 方便开发）
- 读取环境变量 `REIDISQL_TOKEN`
- 添加 Bearer Token 认证中间件（`/api/health` 豁免）
- 启动后 stdout 输出 `READY:{"port":N,"token":"xxx"}` 供 Tauri 解析

```typescript
// Token 认证中间件
const AUTH_TOKEN = process.env.REIDISQL_TOKEN;
if (AUTH_TOKEN) {
  app.use((req, res, next) => {
    if (req.path === '/api/health') return next();
    const auth = req.headers.authorization;
    if (auth !== `Bearer ${AUTH_TOKEN}`) return res.status(401).json({ error: 'Unauthorized' });
    next();
  });
}
```

**修改** `frontend/src/lib/api.ts`
- axios 请求拦截器自动注入 `Authorization: Bearer <token>`
- Token 来源：开发时从 `localStorage` / Vite env；生产时从 Tauri invoke 获取
