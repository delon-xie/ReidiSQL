# ReidiSQL 快速开始指南

> 5 分钟内启动 ReidiSQL 开发环境

## 🚀 快速启动（推荐）

### 方式一：使用初始化脚本

```bash
# 1. 进入项目目录
cd ReidiSQL

# 2. 运行初始化脚本
./init.sh

# 3. 启动开发环境
npm run dev
```

### 方式二：手动安装

```bash
# 1. 进入项目目录
cd ReidiSQL

# 2. 安装所有依赖
npm install
cd frontend && npm install && cd ..
cd node-backend && npm install && cd ..

# 3. 配置环境变量
cp node-backend/.env.example node-backend/.env

# 4. 启动开发环境
npm run dev
```

## 📋 前提条件

确保已安装以下软件：

- ✅ **Node.js 22 LTS** - [下载](https://nodejs.org/)
- ✅ **Rust 1.75+** - [下载](https://rustup.rs/)
- ✅ **Git 2.30+** - [下载](https://git-scm.com/)

验证安装：

```bash
node --version    # 应显示 v22.x.x 或更高
rustc --version   # 应显示 1.75.0 或更高
git --version     # 应显示 2.30.0 或更高
```

## 🎯 启动后验证

### 1. 前端开发服务器

访问：http://localhost:1420

你应该看到：
- 顶部：ReidiSQL 标题栏
- 左侧：数据库连接列表
- 中间：SQL 编辑器
- 下方：查询结果区域

### 2. Node.js 后端

访问：http://localhost:3001/health

你应该看到：
```json
{
  "status": "ok",
  "timestamp": "2026-06-01T..."
}
```

### 3. Tauri 桌面应用

会自动打开一个桌面窗口，显示与前端相同的内容。

## 🐛 常见问题

### Q: TypeScript 报错怎么办？

**A:** 这是正常的！所有 TypeScript 错误都是因为依赖未安装。运行 `npm install` 后会消失。

### Q: 端口被占用怎么办？

**A:** 修改配置文件中的端口号：
- 前端：`frontend/vite.config.ts` → `server.port`
- 后端：`node-backend/.env` → `PORT`

### Q: 如何调试？

**A:** 
- **前端**：浏览器 DevTools（F12）
- **后端**：查看终端日志
- **Tauri**：右键 → 检查元素

### Q: 数据库连接失败？

**A:** 
1. 确保数据库已安装并运行
2. 检查 `node-backend/.env` 配置
3. 测试连接：`curl http://localhost:3001/api/v1/connections/test`
