# 主界面与数据库对象树 PRD

## 1. 功能概述

主界面是 ReidiSQL 的核心工作区域，采用经典的三栏布局设计：左侧数据库对象树、中间工作区（查询/数据/主机）、右侧帮助面板。支持多连接、多标签页、多面板的灵活工作方式。

### 1.1 用户故事

- 作为开发者，我需要同时管理多个数据库连接，并在它们之间快速切换
- 作为 DBA，我需要浏览数据库对象树，快速定位表、视图、存储过程等
- 作为数据分析师，我需要打开多个查询标签页，并行处理不同的查询任务
- 作为团队负责人，我需要收藏常用数据库对象，快速访问

### 5.5 树操作

#### 5.5.1 展开/折叠
- **双击节点**：展开/折叠子节点
- **右键菜单**：全部展开/全部折叠
- **键盘**：`+` 展开，`-` 折叠，`*` 全部展开

#### 5.5.2 拖拽
- **拖拽表名**：到 SQL 编辑器插入表名
- **拖拽列名**：到 SQL 编辑器插入列名
- **拖拽到查询**：自动添加 FROM 子句

#### 5.5.3 双击行为
- **数据库**：切换活动数据库
- **表**：打开表（SELECT * FROM table）
- **视图/过程/函数/触发器/事件**：打开编辑器
- **列**：插入列名到编辑器（可配置）
