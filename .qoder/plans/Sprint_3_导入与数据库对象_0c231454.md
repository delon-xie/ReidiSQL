# Sprint 3: 导入 + 数据库对象

## 范围

基于迁移 PRD Sprint 3 定义，共 4 个交付模块：
1. CSV 导入向导 — 文件格式检测、列映射、导入执行
2. 视图编辑器 — SQL 编辑 + CREATE/ALTER VIEW DDL
3. 存储过程/函数编辑器 — 参数定义 + 代码编辑 + 执行
4. 触发器编辑器 — 事件/时机配置 + SQL body 编辑

## Task 1: 后端 CSV 导入服务

**新建** `node-backend/src/services/importService.ts` (~250 行)

- `detectFormat(content, options)` — CSV 格式检测（分隔符/包围符/列类型）
  - 读取前 N 行，逐字符解析分隔符/包围符
  - 类型检测：Integer / Float / Date / DateTime / Text
- `importCSV(connectionId, database, table, content, options)` — 执行导入
  - 客户端解析模式：逐行解析 CSV，生成 INSERT 语句
  - 支持 INSERT / INSERT IGNORE / REPLACE 模式
  - 分批执行（每批 max 500 行或 0.5MB）
  - 支持清空表（TRUNCATE/DELETE 回退）
- `copyTable(connectionId, srcDb, srcTable, dstDb, dstTable, options)` — 表复制
  - 复制结构（CREATE TABLE ... LIKE）
  - 复制数据（INSERT INTO ... SELECT ... WHERE）
  - 可选复制索引/外键

**新建** `node-backend/src/routes/import.ts` (~80 行)

- `POST /api/import/detect` — 格式检测
- `POST /api/import/execute` — 执行导入
- `POST /api/import/copy` — 表复制

## Task 2: 后端数据库对象 DDL 服务

**新建** `node-backend/src/services/objectDDLService.ts` (~200 行)

- `createView(connId, db, name, definition, options)` — CREATE/ALTER VIEW
- `createRoutine(connId, db, name, type, params, returns, body, options)` — CREATE PROCEDURE/FUNCTION
- `createTrigger(connId, db, name, timing, event, table, body)` — CREATE TRIGGER
- `dropObject(connId, db, type, name)` — DROP VIEW/PROCEDURE/FUNCTION/TRIGGER
- `getRoutineCode(connId, db, name, type)` — SHOW CREATE PROCEDURE/FUNCTION
- `getTriggerCode(connId, db, name)` — SHOW CREATE TRIGGER
- `getViewCode(connId, db, name)` — SHOW CREATE VIEW

**新建** `node-backend/src/routes/objects.ts` (~80 行)

- `POST /api/objects/view` — 创建/修改视图
- `POST /api/objects/routine` — 创建/修改存储过程/函数
- `POST /api/objects/trigger` — 创建/修改触发器
- `DELETE /api/objects/:type/:name` — 删除对象
- `GET /api/objects/:type/:name/code` — 获取对象定义
