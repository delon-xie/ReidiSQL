# ReidiSQL 产品设计文档

## 1. 产品概览

ReidiSQL 是一个功能强大的数据库管理工具，旨在为开发者和数据库管理员提供直观、高效的数据库操作体验。本设计文档详细描述了产品的用户界面设计和交互流程。

---

## 4. 中间查询区域设计

### 4.1 查询标签页

**标签页控件**：
- 标签名称显示查询标题或文件名
- 未保存的查询显示 `*` 标记
- 标签右键菜单：
  - 关闭标签页
  - 关闭其他标签页
  - 关闭所有标签页
  - 重命名标签
  - 保存
  - 另存为...

### 4.2 SQL 编辑器

**功能特性**：

1. **语法高亮**
   - 关键字高亮显示
   - 字符串、数字、注释不同颜色
   - 括号匹配高亮
   - 语法错误标识

2. **代码补全**
   - 关键字自动完成
   - 表名、列名提示
   - 函数提示
   - 快捷键：Ctrl+Space

3. **代码折叠**
   - 按语句块折叠
   - 折叠标记显示在左侧

4. **行号显示**
   - 左侧显示行号
   - 当前行高亮

5. **编辑功能**
   - 撤销/重做
   - 剪切/复制/粘贴
   - 拖放编辑
   - 括号自动匹配

6. **搜索替换**
   - 查找对话框（Ctrl+F）
   - 替换对话框（Ctrl+H）
   - 正则表达式支持
   - 大小写敏感选项

**颜色方案（默认）**：
```
关键字:    蓝色
字符串:    红色
数字:      紫红色
注释:      绿色
标识符:    黑色
背景:      白色
选中:      深蓝色背景，白色文字
当前行:    浅黄色背景
```

### 4.3 帮助面板

帮助面板提供多个功能标签：

#### 列信息标签
显示当前选中表的所有列信息：
- 列名
- 数据类型
- 是否可空
- 默认值
- 注释
- 双击可插入到编辑器

#### 函数标签
显示可用的数据库函数列表：
- 函数分类（字符串、日期、数学、聚合等）
- 函数签名
- 函数说明
- 双击可插入到编辑器

#### 关键字标签
显示 SQL 关键字列表：
- 按字母排序
- 双击可插入到编辑器

#### 代码片段标签
管理常用的 SQL 代码片段：
- 预定义片段
- 用户自定义片段
- 片段分类
- 双击可插入到编辑器

#### 查询历史标签
显示执行过的查询历史：
- 按日期分组
- 查询内容
- 执行时间
- 数据库
- 双击可重新执行

#### 查询分析标签
显示最后执行查询的分析信息：
- EXPLAIN 输出
- 查询执行计划
- 性能建议

#### 参数绑定标签
管理查询参数：
- 参数名称
- 参数值
- 保持选项
- 绑定激活开关

### 4.4 结果标签页

## 7. 交互设计规范

### 7.1 快捷键

| 快捷键 | 功能 |
|--------|------|
| F5 | 刷新 |
| F9 | 执行查询 |
| Ctrl+N | 新建查询 |
| Ctrl+O | 打开查询 |
| Ctrl+S | 保存查询 |
| Ctrl+F | 查找 |
| Ctrl+H | 替换 |
| Ctrl+C | 复制 |
| Ctrl+V | 粘贴 |
| Ctrl+X | 剪切 |
| Ctrl+Z | 撤销 |
| Ctrl+Y | 重做 |
| Ctrl+Space | 代码补全 |
| Ctrl+Tab | 下一个查询标签 |
| Ctrl+Shift+Tab | 上一个查询标签 |
| Ctrl+W | 关闭当前查询标签 |
| Ctrl+F9 | 执行选中部分 |
| Shift+F9 | 执行当前语句 |
| Esc | 停止查询 |
| Insert | 插入新行 |
| Delete | 删除选中行 |

### 7.2 消息提示

**成功消息**：绿色背景，显示在状态栏或弹出对话框
**警告消息**：黄色背景
**错误消息**：红色背景，带错误代码和详细信息

### 7.3 进度显示

- 长时间操作显示进度条
- 可取消的操作显示取消按钮
- 查询执行时显示沙漏光标

### 7.4 确认对话框

- 删除操作要求确认
- 危险操作（如删除数据库）要求二次确认
- 未保存修改时提醒保存
