# PRD-04: 查询执行与结果展示

## 1. 功能概述

查询执行与结果展示模块是 ReidiSQL 的核心数据处理引擎，负责将用户编写的 SQL 发送至数据库服务器执行，并以可视化网格形式呈现结果。该模块支持多种执行模式（全量/选中/当前语句/EXPLAIN）、线程异步执行、多结果集标签页、行内数据编辑、多列排序、列显示控制，以及 16 种格式的数据导出/复制功能。

### 1.1 相关源码

| 文件 | 大小 | 职责 |
|------|------|------|
| `main.pas` | 567KB | 查询执行入口、结果标签页创建、查询历史、线程管理 |
| `exportgrid.pas` | 47KB | 16 种导出格式实现、导出对话框 |
| `grideditlinks.pas` | 59KB | 网格行内编辑器（7 种编辑器类型） |
| `data_sorting.pas` | 10KB | 多列排序对话框 |
| `column_selection.pas` | 8KB | 列显示/隐藏选择器 |
| `reformatter.pas` | 10KB | SQL 格式化（内部 + 在线 API） |

## 4. 功能详细说明

### 4.1 查询执行模式

| 模式 | Action 名称 | 快捷键 | 说明 |
|------|-------------|--------|------|
| 执行全部 | `actExecuteQuery` | F9 | 执行编辑器中所有 SQL 语句 |
| 执行选中 | `actExecuteSelection` | Ctrl+Shift+F9 | 仅执行当前选中的 SQL 文本 |
| 执行当前语句 | `actExecuteCurrentQuery` | Ctrl+F9 | 执行光标所在位置的单条 SQL 语句 |
| EXPLAIN 当前语句 | `actExplainCurrentQuery` | — | 对当前 SELECT 语句执行 EXPLAIN 分析 |

**执行流程** (`actExecuteQueryExecute`)：
1. **SQL 拆分**：创建 `TSQLBatch` 对象，按分隔符（默认 `;`）将 SQL 文本拆分为多条独立语句
2. **绑定参数替换**：若存在绑定参数（`:param_name`），按降序替换以避免名称前缀冲突
3. **安全检查**（可选）：若启用 `asWarnUnsafeUpdates`，检测不含 `WHERE` 子句的 `UPDATE`/`DELETE` 语句，弹出确认对话框
4. **清空旧结果**：清除之前的结果标签页和性能分析数据
5. **性能分析设置**：若在查询助手树中勾选了 Profile 节点，执行 `SET profiling=1`
6. **启动线程**：创建 `TQueryThread` 后台线程执行查询，UI 保持响应

### 4.2 线程执行与回调

| 回调方法 | 时机 | 操作 |
|----------|------|------|
| `BeforeQueryExecution` | 每条语句执行前 | 更新进度条位置 |
| `AfterQueryExecution` | 每条语句完成后 | 创建结果标签页、设置列头、填充网格 |
| `FinishedQueryExecution` | 全部语句完成后 | 错误处理、日志记录、查询历史、性能分析 |

**线程安全**：
- 执行前调用 `Conn.Ping(True)` 确保连接存活，避免 SynEdit 绘制异常
- `Tab.QueryRunning` 标志控制 UI 状态（禁用执行按钮、启用取消按钮）

### 4.3 结果网格

#### 4.3.1 结果标签页 (ResultTab)

- 每条产生结果集的 SQL 语句创建一个 `TResultTab`
- 标签页标题格式：`表名 (行数r × 列数c)`
- 支持通过 SQL 注释指定标签名：`-- names:结果A,结果B`
- 结果标签条的颜色继承自会话颜色 (`SessionColor`)
- 可编辑结果（表名可识别时）显示表图标 (ImageIndex=14)

#### 4.3.2 列头信息

| 属性 | 说明 |
|------|------|
| 列名 | 从查询结果 `ColumnNames[i]` 获取 |
| 对齐方式 | 数值类型（dtcInteger/dtcReal）右对齐，其余左对齐 |
| 图标 | 主键列：`ICONINDEX_PRIMARYKEY`；唯一键：`ICONINDEX_UNIQUEKEY`；索引键：`ICONINDEX_INDEXKEY` |
| 提示信息 | 显示来源表名 (`Source table: xxx`) |
| 行号列 (#) | 第一列为固定行号列，可通过 `asShowRowId` 设置显示/隐藏 |

#### 4.3.3 行内编辑器 (grideditlinks.pas)

根据列的数据类型自动选择编辑器类型：

| 编辑器类 | 适用类型 | 功能 |
|----------|----------|------|
| `TInplaceEditorLink` | 通用文本/数值 | 基础文本编辑，带可选按钮（调用文本编辑器） |
| `THexEditorLink` | BLOB/二进制 | 十六进制编辑器窗口 |
| `TDateTimeEditorLink` | DATE/TIME/DATETIME | 日期时间掩码编辑 + UpDown 微调，支持键盘增减日期 |
| `TEnumEditorLink` | ENUM | 下拉组合框，值列表来自列定义 |
| `TSetEditorLink` | SET | CheckListBox 多选面板 + OK/Cancel 按钮 |
| `TColumnDefaultEditorLink` | 表设计器-默认值 | 单选组：无/文本/NULL/表达式/自增 |
| `TDataTypeEditorLink` | 表设计器-数据类型 | VirtualStringTree 树形选择器 + 帮助说明 |

**编辑器通用行为**：
- `Tab` 键跳转到下一个可见列/行
- `Shift+Tab` 跳转到上一个可见列/行
- `Enter` 键确认编辑
- `Escape` 键取消编辑
- `F2` 键开始编辑当前单元格

### 4.4 数据排序 (data_sorting.pas)

**对话框功能**：
- 动态创建排序列控件：序号标签 + 列名下拉框 + ASC/DESC 切换按钮 + 删除按钮
- `添加列`：自动选择第一个未使用的列名作为默认值；若所有列已使用则重复第一列
- `重置排序`：清除所有排序项（调用 `MainForm.actDataResetSorting` 状态）
- OK 按钮仅在当前排序与原始排序不同时启用（通过比较 ORDER 子句字符串判断）
- 点击对话框外部区域自动关闭（FormDeactivate）

**排序存储**：
- 排序项保存在 `MainForm.DataGridSortItems`（`TSortItems` 对象）
- 确认后触发网格数据重新加载 (`InvalidateVT`)

### 4.5 列选择 (column_selection.pas)

**对话框功能**：
- 复选列表显示所有可用列，勾选状态反映当前显示/隐藏状态
- `全选/取消全选` 复选框支持三种状态：全选/全不选/部分选中（灰色）
- `过滤` 输入框：按列名模糊过滤（大小写不敏感），左侧按钮可快速清除/恢复过滤文本
- `按字母排序` 复选框：切换列名的排序方式（字母序 vs 原始表定义序）
- `显示行 ID` 复选框：控制行号列 (#) 的显示

**存储**：
- 隐藏列列表保存在 `MainForm.DataGridHiddenColumns`（`TStringList`）
- 排序偏好保存在 `asDisplayedColumnsSorted`
- 行 ID 偏好保存在 `asShowRowId`
- 窗口尺寸 DPI 感知保存

### 4.6 数据导出 (exportgrid.pas)

#### 4.6.1 支持的导出格式

| 格式 | 枚举值 | 文件扩展名 | 说明 |
|------|--------|------------|------|
| Excel CSV | `efExcel` | .csv | Tab/分号/逗号分隔（自动适配区域设置），UTF-8 BOM |
| Delimited text | `efCSV` | .csv | 自定义分隔符/包围符/终止符 |
| HTML table | `efHTML` | .html | 完整 XHTML 文档，含 CSS 样式，支持暗色模式 |
| XML | `efXML` | .xml | mysqldump 兼容格式，支持 xsi:nil |
| SQL INSERTs | `efSQLInsert` | .sql | `INSERT INTO table (cols) VALUES (...)` |
| SQL INSERT IGNOREs | `efSQLInsertIgnore` | .sql | `INSERT IGNORE INTO table ...` |
| SQL REPLACEs | `efSQLReplace` | .sql | `REPLACE INTO table ...` |
| SQL DELETEs/INSERTs | `efSQLDeleteInsert` | .sql | 每行先 DELETE 再 INSERT |
| SQL UPDATEs | `efSQLUpdate` | .sql | `UPDATE table SET ... WHERE pk=...` |
| LaTeX | `efLaTeX` | .LaTeX | `\begin{tabular}` 表格环境，数值用 `$...$` 包围 |
| Textile | `efTextile` | .textile | Redmine/Textile 格式 |
| Jira Textile | `efJiraTextile` | .jira-textile | Jira wiki markup 格式 |
| PHP Array | `efPHPArray` | .php | `$tableName = [...]`，支持单引号/双引号字符串 |
| Markdown Here | `efMarkDown` | .md | Markdown 表格（`| col | col |`） |
| JSON | `efJSON` | .json | `{"table":"...","rows":[...]}` |
| JSON Lines | `efJSONLines` | .jsonl | 每行一个 JSON 对象 |

#### 4.6.2 导出选项

| 选项 | 适用格式 | 说明 |
|------|----------|------|
| 包含列名 | 全部 | 在表头/首行输出列名 |
| 包含自增列 | 全部 | 是否包含 AUTO_INCREMENT 列（仅当存在时启用） |
| 仅当前列 | 全部 | 只导出当前聚焦的列 |
| 包含查询语句 | HTML/XML/Markdown/JSON | 在头部输出原始 SQL（HTML 中用 `<pre>`，Markdown 中用代码块） |
| 移除换行符 | 全部 | 将单元格内的换行符去除 |
| 导出后打开文件 | 文件模式 | 导出完成后用默认程序打开文件 |

#### 4.6.3 CSV 特殊字符菜单

右键按钮弹出菜单，支持插入特殊字符：
- Tab (`\t`)、逗号 (`,`)、分号 (`;`)、单引号 (`'`)、双引号 (`"`)
- Unix 换行 (`\n`)、Mac 换行 (`\r`)、Windows 换行 (`\r\n`)
- NUL (`\0`)、Backspace (`\b`)、Ctrl+Z (`\x1A`)

#### 4.6.4 输出目标

| 目标 | 说明 |
|------|------|
| 剪贴板 | 编码为 UTF-8；SQL 格式额外提供 HTML 高亮版本（<100KB 时） |
| 文件 | 支持编码选择（不含 Auto detect）、文件名占位符、最近文件历史 |

**文件名占位符**：通过下拉菜单插入动态占位符（如 `%d`=数据库名、`%t`=表名等），运行时自动替换

#### 4.6.5 Excel CSV 智能分隔符

- 复制到剪贴板时使用 Tab（`\t`）以便直接粘贴到 Excel
- 文件导出时：若系统小数分隔符为逗号，使用分号（`;`）；否则使用逗号（`,`）
- UTF-8 文件写入 BOM（`EF BB BF`）以兼容新版 Excel

#### 4.6.6 "复制为" 快捷操作

在主窗口数据网格右键菜单中提供 `Copy as` 子菜单，动态生成 16 个 Action：
- Action 名称：`actCopyAs0` ~ `actCopyAs15`
- 点击后直接以对应格式复制选中单元格到剪贴板（隐藏模式对话框）
- 剪贴板默认设置可通过 `btnSetClipboardDefaults` 持久化

### 4.7 查询结果元信息

查询完成后在日志面板输出以下信息：

```
Affected rows: 0  Found rows: 100  Warnings: 0  Duration for 1 query: 0.015 sec. (+ 0.002 sec. network)
```

| 指标 | 说明 |
|------|------|
| Affected rows | 受影响的行数（INSERT/UPDATE/DELETE） |
| Found rows | 查询返回的行数（SELECT） |
| Warnings | 服务器警告数量 |
| Duration | 服务器端执行耗时 |
| Network | 网络传输耗时（附加） |

### 4.8 查询性能分析 (Profiling)

- 前提：查询助手树中勾选 Profile 节点
- 执行 `SET profiling=1`，查询后 `SHOW PROFILE`
- 结果展示在查询助手树的 Profile 节点下
- 计算总耗时 (`ProfileTime`) 和最大单步耗时 (`MaxProfileTime`)
- 完成后执行 `SET profiling=0`
- 要求 MySQL 5.0.37+，且服务器未配置 `--disable-profiling`

### 4.9 查询历史

**触发条件**（全部满足）：
- 偏好设置 `asQueryHistoryEnabled` 为 True
- 查询无错误
- 批量语句数 ≤ 5
- SQL 文本大小 ≤ 1 MB

**存储结构**（注册表/设置路径）：
```
SessionPath\QueryHistory\{N} = "时间|数据库|耗时|SQL"
```

**清理策略**：
- 删除与当前 SQL 完全相同的旧记录（避免重复）
- 删除超过 `KeepDays` 天的记录
- 总大小超过 1 MB 时删除最早记录

### 4.10 错误处理

- 执行出错时在编辑器中定位到错误位置：
  - 解析 MySQL 错误消息中的 SQL 片段（如 `near 'xxx' at line N`）
  - 在编辑器中设置光标到匹配位置并高亮错误行
- 进度条切换为错误状态 (`pbsError`)
- 弹出错误对话框

### 4.11 SQL 格式化 (reformatter.pas)

| 格式化器 | 说明 |
|----------|------|
| 内部格式化器 | 基于 MySQL 关键字列表，关键字转大写，重要关键字（SELECT/FROM/WHERE/JOIN等）前插入换行，去除多余空格，保留注释 |
| heidisql.com 在线 | 调用 `APPDOMAIN/sql-formatter.php`，使用 Doctrine SQL Formatter (Jeremy Dorn) |
| sqlformat.org 在线 | 调用 `sqlformat.org/api/v1/format`，支持缩进宽度和关键字大写设置 |

**对话框行为**：
- 可选择默认格式化器并勾选"不再询问"跳过对话框
- 在线格式化器显示提供者链接
- 格式化耗时记录到日志

### 4.12 数据预览面板

- 位于结果网格下方，可折叠
- 当聚焦列为二进制类型 (dtcBinary) 时启用
- 显示图片预览或二进制内容十六进制视图
- 高度保存在 `asDataPreviewHeight`，启用状态保存在 `asDataPreviewEnabled`

## 5. 业务规则与约束

| ID | 规则 | 说明 |
|----|------|------|
| BR-4.1 | 不安全查询警告 | 无 WHERE 子句的 UPDATE/DELETE 语句执行前弹出确认对话框（可通过偏好设置关闭） |
| BR-4.2 | 连接存活检查 | 执行前调用 `Ping(True)` 检测连接状态，避免在已断开的连接上执行 |
| BR-4.3 | BLOB 处理 | 二进制/空间类型列默认以 HEX 格式显示/导出；启用 `actBlobAsText` 时按文本处理 |
| BR-4.4 | NULL 处理 | 导出时 NULL 值使用用户指定的 NULL 占位符文本（默认 "NULL"）；SQL 格式输出字面量 NULL |
| BR-4.5 | 数值精度 | 数值类型列在 Excel/HTML/Markdown 导出时使用本地化数字格式（千分位等） |
| BR-4.6 | 文件覆盖确认 | 导出文件已存在时弹出覆盖确认对话框 |
| BR-4.7 | 大小估算 | 导出对话框显示选中行/全部行的字节大小估算（基于前 1000 行插值） |
| BR-4.8 | 自增列排除 | 可选择排除 AUTO_INCREMENT 列（常用于 INSERT 语句生成） |
| BR-4.9 | 日期时间精度 | Excel CSV 导出时自动去除日期时间值的毫秒部分（Excel 不支持） |
| BR-4.10 | 编码 BOM | Excel CSV 以 UTF-8 编码保存时写入 BOM（3字节），确保 Excel 正确识别 |

## 7. 边界情况

| 场景 | 处理方式 |
|------|----------|
| 空结果集 | 创建标签页显示 "0r × Nc"，网格无数据行 |
| 无结果集的语句（INSERT/UPDATE/DELETE） | 不创建结果标签页，仅在日志中显示影响行数 |
| 连接断开 | 执行前 Ping 检测，失败时抛出异常并显示错误对话框 |
| 超大结果集 | 网格使用 VirtualStringTree 虚拟模式，按需加载行数据（`VTREE_NOTLOADED`） |
| 导出文件不可写 | 捕获 `EFCreateError`，弹出错误对话框，保持导出对话框打开 |
| 在线格式化网络错误 | 捕获 `EIdHTTPProtocolException`，显示 HTTP 错误消息，保持对话框打开 |
| 查询执行取消 | 通过 `actCancelQuery` 中断线程，清理部分结果 |
| 绑定参数无值 | 未设置值的参数不进行替换，保留原始占位符文本 |
| 多结果集数量 > 10 | 正常创建所有标签页，标签条可滚动 |
| 性能分析不可用 | 捕获异常，显示 MySQL 版本要求提示，禁用本次性能分析 |
| 网格编辑器 Tab 跳转 | 到达最后一列时自动跳转到下一行首列，反之亦然；无更多行时结束编辑 |
| 列名包含特殊字符 | 导出时使用对应格式的转义函数（HTML: `HTMLSpecialChars`，JSON: `FormatJson`，CSV: 包围符双写） |
| 最近文件列表 | 最多保留 10 个文件路径，按使用时间排序 |
