# SQL 编辑器 PRD

## 1. 功能概述

SQL 编辑器是 ReidiSQL 的核心组件，基于 SynEdit 控件构建，提供语法高亮、代码补全、代码折叠、查找替换等专业的 SQL 编辑功能。支持多标签页并行查询，与帮助面板（列、函数、关键字、代码片段、历史、参数绑定）紧密集成。

### 1.1 用户故事

- 作为开发者，我需要语法高亮来快速识别 SQL 关键字、字符串、注释
- 作为 DBA，我需要代码补全来提高编写效率，减少拼写错误
- 作为数据分析师，我需要代码折叠来管理复杂的嵌套查询
- 作为团队负责人，我需要保存常用 SQL 片段以便复用

### 4.2 补全内容

## 9. SQL 格式化

### 9.1 格式化选项

| 选项 | 说明 | 快捷键 |
|------|------|--------|
| 内部格式化 | 使用内置格式化引擎 | - |
| 在线格式化 (HeidiSQL) | 使用 heidisql.com API | - |
| 在线格式化 (sqlformat.org) | 使用 sqlformat.org API | - |

### 9.2 内部格式化规则

**关键字大写**：
```sql
-- 格式化前
select * from users where id=1

-- 格式化后
SELECT * FROM users WHERE id = 1
```

**换行规则**：
```sql
-- 格式化前
SELECT u.id, u.name, o.order_date FROM users u LEFT JOIN orders o ON u.id = o.user_id WHERE u.status = 'active' ORDER BY o.order_date DESC

-- 格式化后
SELECT
  u.id,
  u.name,
  o.order_date
FROM
  users u
LEFT JOIN orders o ON u.id = o.user_id
WHERE
  u.status = 'active'
ORDER BY
  o.order_date DESC
```

**重要关键字换行**：
- SELECT, FROM, LEFT, RIGHT, INNER, JOIN
- WHERE, GROUP, ORDER, HAVING, LIMIT
- CREATE, DROP, UPDATE, INSERT, DELETE

**配对关键字**：
- LEFT JOIN, RIGHT JOIN, INNER JOIN
- GROUP BY, ORDER BY

### 9.3 格式化配置

- **记住选择**：可记住上次使用的格式化器
- **不再询问**：跳过格式化器选择对话框

## 16. 自动保存与恢复

### 16.1 自动备份

- **触发条件**：查询内容变更后定时备份
- **备份位置**：应用数据目录
- **命名规则**：`query_N_backup.sql`

### 16.2 恢复机制

- **崩溃恢复**：重启时检测未保存的备份
- **提示恢复**：询问是否恢复未保存的内容
- **清理**：恢复后自动删除备份文件

### 16.3 标签页持久化

- **定时保存**：定时保存所有标签页状态
- **恢复标签**：重启时恢复所有查询标签
- **文件关联**：保持与文件的关联关系

## 17. 其他功能

### 17.1 自动换行

- **切换**：工具栏按钮或菜单
- **模式**：按窗口宽度换行，不插入换行符

### 17.2 制表符设置

| 选项 | 说明 |
|------|------|
| 制表符宽度 | 空格数（默认 2/4） |
| 使用空格 | 将 Tab 转换为空格 |
| 智能缩进 | 自动缩进到上一行位置 |

### 17.3 文件编码

| 编码 | 说明 |
|------|------|
| UTF-8 | 默认编码 |
| UTF-8 BOM | 带 BOM 的 UTF-8 |
| ANSI | 系统默认编码 |
| UTF-16 LE | 小端 Unicode |
| UTF-16 BE | 大端 Unicode |

### 17.4 行尾格式

| 格式 | 说明 |
|------|------|
| Windows (CRLF) | `\r\n` |
| Unix (LF) | `\n` |
| Mac (CR) | `\r` |

### 17.5 语句分隔符

- **默认**：分号 `;`
- **自定义**：可设置其他分隔符（如 `GO`、`//`）
- **用途**：执行时按分隔符拆分语句
