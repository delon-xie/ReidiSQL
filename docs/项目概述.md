# ReidiSQL 项目概述

## 1. 项目简介

ReidiSQL 是一个强大的、开源的数据库管理工具，作为 HeidiSQL 的克隆/分支版本，提供了图形化界面来管理多种类型的数据库服务器。该项目使用 Delphi/VCL 技术栈开发，专为 Windows 平台设计。

### 1.1 主要功能特性

- **多数据库支持**：支持 MySQL/MariaDB、Microsoft SQL Server、PostgreSQL、SQLite、Interbase 和 Firebird
- **可视化数据管理**：直观的用户界面，支持浏览、创建、编辑和删除数据库对象
- **SQL 编辑器**：内置的高级 SQL 编辑器，支持语法高亮、代码补全、查询执行
- **数据导入导出**：支持多种格式的数据导入和导出
- **表结构管理**：可视化的表编辑、索引管理、外键约束设置
- **用户权限管理**：完整的用户和权限管理功能
- **查询历史记录**：保存和管理执行过的 SQL 查询
- **多语言支持**：内置国际化支持
- **主题支持**：支持多种界面主题

### 1.2 技术栈

| 组件 | 技术/工具 |
|------|-----------|
| 开发语言 | Delphi (Object Pascal) |
| 图形界面 | VCL (Visual Component Library) |
| 代码编辑器 | SynEdit |
| 树形视图 | VirtualTreeView |
| 数据库访问 | FireDAC (FireDAC Data Access Components) |
| 国际化 | GNU Gettext |
| 主题系统 | VCL Styles |

## 2. 项目结构

```
ReidiSQL/
├── components/           # 第三方组件
│   ├── synedit/         # SynEdit 代码编辑器组件
│   └── virtualtreeview/ # VirtualTreeView 树形视图组件
├── extra/               # 额外的工具和脚本
│   └── internationalization/ # 国际化相关
├── out/                 # 输出文件和资源
│   ├── plugins64/       # 64位插件
│   └── Snippets/        # SQL 代码片段
├── packages/            # 项目包文件
│   ├── Delphi12.1/     # Delphi 12.1 项目文件
│   └── Delphi12.3/     # Delphi 12.3 项目文件
├── res/                 # 资源文件
│   └── updater/         # 更新工具
├── source/              # 源代码目录
│   ├── detours/         # API 钩子库
│   ├── sizegrip/        # 大小调整组件
│   ├── vcl-styles-utils/ # VCL 样式工具
│   ├── *.pas            # 核心源文件
│   └── *.dfm            # 窗体设计文件
├── build-res.bat        # 资源构建脚本
├── build.php            # 构建脚本
├── CONTRIBUTING.md      # 贡献指南
├── LICENSE              # 许可证
└── readme.md            # 项目说明
```

## 3. 支持的数据库系统

### 3.1 MySQL / MariaDB

- 完整的 MySQL 和 MariaDB 支持
- 支持 TCP/IP、命名管道和 SSH 隧道连接
- 支持版本 5.x 至最新版本

### 3.2 Microsoft SQL Server

- 支持 SQL Server 的所有主要版本
- 支持 TCP/IP、命名管道等连接方式

### 3.3 PostgreSQL

- 完整的 PostgreSQL 支持
- 支持 TCP/IP 和 SSH 隧道连接

### 3.4 SQLite

- 本地文件数据库支持
- 支持加密的 SQLite 数据库

### 3.5 Interbase / Firebird

- 支持 Interbase 和 Firebird 数据库
- 支持 TCP/IP 和本地连接

## 4. 核心功能模块

### 4.1 连接管理模块

- 管理多个数据库服务器连接
- 支持保存连接配置
- 支持连接分组

### 4.2 数据库对象浏览

- 树形结构显示数据库、表、视图、存储过程等
- 支持对象的右键菜单操作

### 4.3 数据编辑模块

- 网格显示和编辑表数据
- 支持插入、更新、删除操作
- 支持二进制数据编辑
- 支持大字段编辑

### 4.4 SQL 查询模块

- 高级 SQL 编辑器（基于 SynEdit）
- 语法高亮
- 代码补全和建议
- 查询执行和结果显示
- 查询历史记录
- 查询参数绑定

### 4.5 表结构编辑

- 可视化的表结构编辑器
- 字段类型设置
- 索引管理
- 外键约束设置
- 表选项配置

### 4.6 数据导入导出

- 支持多种格式的导入导出
- CSV、SQL、XML 等格式
- 批量数据操作

### 4.7 用户权限管理

- 用户创建和删除
- 权限分配
- 角色管理

## 5. 开发环境要求

### 5.1 硬件要求

- 处理器：现代 x86/x64 处理器
- 内存：至少 2GB RAM，推荐 4GB+
- 磁盘空间：至少 500MB 可用空间

### 5.2 软件要求

- 操作系统：Windows 7 或更高版本
- 开发工具：Delphi 12.1 或 Delphi 12.3
- 必需组件：
  - SynEdit
  - VirtualTreeView
  - madExcept（用于错误报告）
