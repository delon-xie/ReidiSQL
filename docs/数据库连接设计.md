# ReidiSQL 数据库连接设计

## 1. 连接架构概览

ReidiSQL 采用分层架构设计来支持多种数据库系统，通过抽象基类和派生类实现数据库特定功能。

### 1.1 架构层次

```
┌───────────────────────────────────────────┐
│       应用层 (主窗体、对话框等)        │
└────────────────┬──────────────────────────┘
                 │
┌────────────────▼──────────────────────────┐
│    TDBConnection 抽象基类               │
│  (dbconnection.pas)                      │
└────────────────┬──────────────────────────┘
                 │
        ┌────────┼────────┐
        │        │        │
┌───────▼───┬──▼──────┬──▼──────────┐
│ MySQL    │ MSSQL   │ PostgreSQL │
│          │         │            │
└───────┬───┴──┬──────┴──┬───────────┘
        │      │         │
┌───────▼───┬──▼──────┬──▼──────────┐
│ SQLite   │Interbase│ Firebird   │
└───────────────────────────────────┘
        │
┌───────▼──────────────────────┐
│  FireDAC 数据访问层        │
│  (或原生数据库驱动)         │
└──────────────────────────────┘
        │
┌───────▼──────────────────────┐
│      数据库服务器           │
└──────────────────────────────┘
```

**文件位置**: `source/dbconnection.pas`

**职责**:
- 定义所有数据库连接共有的接口

## 6. 连接流程

### 6.1 连接建立流程

```
用户点击连接
     │
     ▼
TconnForm.ShowModal (连接对话框)
     │
     ▼
用户配置连接参数
     │
     ▼
用户点击"打开"
     │
     ▼
创建 TDBConnection 派生类实例
     │
     ▼
TDBConnection.Connect
     │
     ├─► 初始化 FireDAC 连接参数
     │
     ├─► 尝试连接
     │
     ├─► 获取服务器版本
     │
     └─► 初始化 SQL 提供者
     │
     ▼
连接成功，加载数据库列表
     │
     ▼
更新对象树
     │
     ▼
显示主界面
```

### 6.2 查询执行流程

```
用户输入 SQL 并点击执行
     │
     ▼
TQueryTab.Execute
     │
     ▼
创建 TQueryThread (异步执行)
     │
     ▼
TDBConnection.Execute
     │
     ▼
FireDAC 执行查询
     │
     ▼
获取结果集
     │
     ▼
填充结果网格
     │
     ▼
记录查询历史
     │
     ▼
显示执行统计
```

### 6.3 对象树加载流程

```
用户展开节点
     │
     ▼
检查加载状态
     │
     ├─ 已加载 → 显示子节点
     │
     └─ 未加载
          │
          ▼
     查询数据库获取子对象
          │
          ▼
     创建 TDBObject 实例
          │
          ▼
     添加到树节点
          │
          ▼
     标记为已加载
```

  // 执行多个操作

### 8.2 错误处理示例

```pascal
try
  DBConnection.Execute('INSERT INTO ...');
except
  on E: EDbError do
  begin
    ShowMessageFmt('错误 %d: %s' + sLineBreak + '提示: %s',
      [E.ErrorCode, E.Message, E.Hint]);
  end;
  on E: Exception do
  begin
    ShowMessage('发生错误: ' + E.Message);
  end;
end;
```
