# 连接管理 PRD

## 1. 功能概述

连接管理器是 ReidiSQL 的入口界面，负责管理所有数据库连接会话。用户可以创建、编辑、删除、组织连接会话，支持文件夹分组、拖拽排序、搜索过滤等功能。每个会话包含完整的连接参数（网络类型、认证、SSH隧道、SSL、高级选项等）。

### 1.1 用户故事

- 作为开发者，我需要管理多个数据库连接，以便快速切换到不同的开发/测试/生产环境
- 作为 DBA，我需要使用 SSH 隧道安全地连接到远程数据库
- 作为运维人员，我需要为不同连接设置不同的颜色标识，避免误操作生产环境
- 作为团队负责人，我需要导入/导出连接配置，方便团队成员共享

## 3. 功能详细说明

### 3.1 会话列表（左侧面板）

#### 3.1.1 树形结构
- **支持文件夹**：会话可以组织在文件夹中，支持多层嵌套
- **节点类型**：
  - 📁 文件夹节点：仅用于分组，不可连接
  - 🗄️ 会话节点：可连接的数据库会话
- **修改标记**：未保存的会话名称后显示 `*` 符号
- **自定义背景色**：每个会话可设置独立的背景颜色，用于视觉区分

#### 3.1.2 列信息
| 列名 | 说明 | 可见性 |
|------|------|--------|
| Session name | 会话名称（支持内联编辑） | 始终可见 |
| Host | 主机名 | 可配置 |
| User | 用户名 | 可配置 |
| Version | 服务器版本 | 可配置 |
| Last connect | 最后连接时间 | 可配置 |
| Counter | 连接次数统计 | 可配置 |
| Comment | 注释 | 可配置 |

#### 3.1.3 搜索过滤
- **位置**：左侧面板顶部
- **功能**：实时过滤会话列表（500ms 延迟）
- **快捷键**：Ctrl+F
- **清除按钮**：点击右侧 ✕ 图标清除过滤

#### 3.1.4 排序
- **默认**：按会话名称排序
- **文件夹置顶**：可选选项，文件夹始终显示在会话上方
- **点击列头**：可切换排序列和方向

#### 3.1.5 拖拽排序
- **支持**：拖动会话/文件夹到新位置
- **限制**：
  - 不能将文件夹拖入自身
  - 不能将节点拖到同级相同位置
  - 目标文件夹不能存在同名会话

## 4. 业务规则与约束

### 4.1 会话命名规则
- 不能包含反斜杠 `\`（自动替换为 `-`）
- 同一文件夹内不能重名
- 大小写变更需要先改为其他名称再改回

### 4.2 修改保存机制
- **自动检测修改**：实时比较当前值与保存值
- **修改标记**：会话名后显示 `*`
- **切换会话时**：提示保存/放弃/取消
- **关闭窗口时**：提示保存未保存的修改

### 4.3 连接参数验证
| 参数 | 验证规则 |
|------|----------|
| 端口 | 0-65535，0 表示使用默认端口 |
| SSH 端口 | 1-65535 |
| SSH 超时 | 1-999 秒 |
| 查询超时 | 0-9999 秒，0 表示无限制 |
| 保持连接 | 0-9999 秒，0 表示禁用 |

### 4.4 互斥选项
- **登录提示** 与 **Windows 认证** 互斥（不能同时启用）
- **登录提示** 仅在 MySQL/MSSQL/PgSQL 可用
- **Windows 认证** 仅在 MSSQL/MySQL 可用
- **压缩协议** 仅 MySQL 可用
- **本地时区** 仅 MySQL 可用
- **SSL** 仅在 TCP/IP 连接可用

## 6. 边界情况

### 6.1 首次启动
- 无会话时显示引导帮助文本
- "打开"按钮禁用
- 提示用户点击"新建"创建第一个会话

### 6.2 导入配置后
- 自动刷新会话列表
- 10 秒内未检测到新会话，提示重启应用

### 6.3 连接失败
- 显示错误对话框
- 统计标签页记录失败次数
- "打开"按钮恢复可用

### 6.4 拖拽错误
- 目标存在同名会话：显示错误，拒绝移动
- 注册表操作失败：显示错误信息

### 6.5 多显示器
- 窗口位置保存
- 显示器断开后自动调整到可见区域
