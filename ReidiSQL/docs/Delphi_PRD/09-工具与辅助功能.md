# PRD-09: 工具与辅助功能

## 4. 功能详细说明

### 4.1 表工具 (TfrmTableTools)

#### 4.1.1 工具模式 (TToolMode)
| 模式 | 标签页 | 按钮文字 | 描述 |
|------|--------|----------|------|
| tmMaintenance | Maintenance | Execute | 表维护操作 |
| tmFind | Find | Find | 全文搜索 |
| tmSQLExport | SQL Export | Export | SQL 导出 |
| tmBulkTableEdit | Bulk edit | Update | 批量表编辑 |
| tmGenerateData | Generate | Generate | 数据生成 |

#### 4.1.2 对象树
- **TreeObjects**: 复用 MainForm.DBtree 的树结构
- 所有节点带三态复选框
- 数据库过滤器 `editDatabaseFilter` + 表过滤器 `editTableFilter`: 正则表达式匹配，`;` 分隔多条件
- 右键菜单: Check all / Check by type / Check none / Invert check
- 选中统计: 对象数量 + 总大小（异步计算 timerCalcSize）
- 支持 PreSelectObjects 预选中

#### 4.1.3 表维护 (Maintenance)
- **操作类型**: Check / Analyze / Checksum / Optimize / Repair
- **选项**（按操作类型动态启用）:
  - Quick: CHECK/REPAIR/CHECKSUM
  - Fast: CHECK
  - Medium: CHECK
  - Extended: CHECK/REPAIR/CHECKSUM
  - Changed: CHECK
  - Use_frm: REPAIR
  - For upgrade: CHECK
- Checksum 的 Quick/Extended 互斥
- 生成 SQL: `{OPERATION} TABLE db.table [QUICK] [FAST] [MEDIUM] [EXTENDED] [CHANGED] [USE_FRM] [FOR UPGRADE]`
- 结果网格显示: Database / Table / Op / Msg_type / Msg_text

#### 4.1.4 全文搜索 (Find)
- **搜索文本**: memoFindText（简单文本）/ SynMemoFindText（SQL 条件，带语法高亮和补全）
- **数据类型过滤**: 全部 / Integer / Real / Text / Binary / Date / Other
- **匹配类型**: Contains / Exact / Begins with / Ends with / RegEx
- **大小写敏感**: 复选框（SQL 模式下禁用）
- 搜索逻辑:
  - 表/视图: 遍历匹配的列，构建 WHERE 子句，统计匹配行数和相关度百分比
  - 存储过程/函数: 在 `information_schema.routines.routine_definition` 中搜索
  - 多方言支持: MySQL(LIKE BINARY/REGEXP) / MSSQL(COLLATE) / PgSQL(ILIKE/SIMILAR) / SQLite(LIKE/REGEXP)
- **See Results 按钮**: 自动创建查询标签，执行所有匹配的 SELECT 语句
- 搜索设置持久化到注册表

#### 4.1.5 SQL 导出 (SQL Export)
**结构选项**:
- Create databases (`CREATE DATABASE`)
- Drop databases (`DROP DATABASE`)
- Create tables (`CREATE TABLE`)
- Drop tables (`DROP TABLE`)

**数据选项**:
- No data
- Delete + insert (truncate)
- Insert
- Insert ignore
- Replace existing (UPDATE/REPLACE)
- Insert size 限制 (KB, UpDown)

**输出类型**:
| 类型 | 说明 |
|------|------|
| Single .sql file | 单个 SQL 文件 |
| ZIP compressed | ZIP 压缩的 .sql 文件 |
| Directory | 每个对象一个文件，按数据库子目录 |
| Clipboard | 复制到剪贴板 |
| Database | 导出到同服务器另一数据库 |
| Server: session | 导出到其他服务器 |

**高级选项** (popupExportOptions):
- Add comments (添加注释)
- Use transactions (使用事务)
- Remove auto_increment (移除自增值)
- Remove definer (移除 DEFINER)

**导出流程**:
1. 设置 SQL_MODE/TIME_ZONE/FOREIGN_KEY_CHECKS 等会话变量
2. 遍历选中数据库的选中对象
3. 触发器延后到最后导出
4. 视图在最后再导出一次（确保引用表已创建）
5. 输出 Footer（恢复会话变量）
6. ZIP 模式下先写临时文件再压缩
7. 重置本地 SQL_MODE/TIME_ZONE

**mysqldump 命令复制**: 右键菜单生成等效 mysqldump 命令行

#### 4.1.6 批量表编辑 (Bulk Table Edit)
- **移动到数据库**: RENAME TABLE（表）/ 重建视图（视图）
- **重置自增**: ALTER TABLE AUTO_INCREMENT=0
- **修改排序规则**: ALTER TABLE CONVERT TO COLLATE
- **修改字符集**: 通过排序规则推断
- **修改引擎**: ALTER TABLE ENGINE=
- 每项需勾选复选框才生效

#### 4.1.7 数据生成 (Generate Data)
- **行数**: UpDown 控件
- **NULL 比例**: 0-100%
- 根据列数据类型生成随机数据:
  - 整数: RandomRange
  - 浮点: Random
  - 字符串: 随机长度文本
  - 日期: 随机日期
  - 枚举: 随机选择枚举值
  - JSON: 空 JSON 对象
  - 二进制: 随机字节
- 非表/视图对象跳过

#### 4.1.8 结果网格
- **ResultGrid** (TVirtualStringTree): 4 列
- 列头排序
- 动态列标题（根据操作类型变化）
- 红色高亮错误行

#### 4.1.9 执行流程
- Execute 按钮: 开始执行，变为 Cancel
- 执行期间禁用标签页切换和对象树
- 进度条: MainForm.EnableProgress
- 异常处理: EDbError / EFCreateError / EInOutError → 错误日志 + 可选取消
- "Unknown database" (错误码 1049) → 强制取消

### 4.2 数据库同步 (TfrmSyncDB)

#### 4.2.1 源选择
- **treeSource**: 复用 MainForm.DBtree 结构
- 复选框: 数据库和表级别
- 仅允许勾选一个数据库下的表

#### 4.2.2 目标配置
- 服务器: 下拉选择已保存会话
- 数据库: 连接后列出所有数据库，或 "Same as source"
- 表: 列出目标数据库的表，或 "Same as source"

#### 4.2.3 分析差异 (btnAnalyze)
- 遍历源数据库选中的表
- 在目标数据库中检查同名同类型对象是否存在
- 差异类型: diCreate（创建缺失）/ diAlter（修改）/ diInsert（插入数据）
- 当前仅实现 diCreate（对象不存在时生成 CREATE 语句）

#### 4.2.4 差异树
- **treeDifferences**: 两级结构
  - 第 0 级: 对象名 + 图标
  - 第 1 级: 差异项（Create/Alter/Insert + 图标）
- 三态复选框，可勾选要应用的差异

#### 4.2.5 应用差异 (btnApply)
- 当前为空实现（TODO）

### 4.3 SQL 帮助 (TfrmSQLhelp)

#### 4.3.1 主题树
- **treeTopics**: 懒加载的树形结构
- 数据源: `HELP_KEYWORD` / `HELP_CATEGORY` 系统表（通过 qHelpKeyword SQL）
- 节点类型: 分类（文件夹图标）/ 关键字（文档图标）
- 递归保护: 检测重复分类名避免无限递归

#### 4.3.2 内容显示
- 选中关键字后查询 description 和 example
- **memoDescription**: 描述文本
- **MemoExample**: SQL 示例代码
- 无内容时显示提示信息

#### 4.3.3 过滤
- **editFilter**: 实时搜索（Timer 延迟）
- 隐藏不匹配的叶节点和空分类
- 匹配的分类自动展开

#### 4.3.4 关键字定位 (SetKeyword)
- 外部设置关键字时自动在树中查找并选中
- 先搜索已初始化的节点，再搜索未初始化的

#### 4.3.5 在线搜索
- 按钮跳转: `{APPDOMAIN}sqlhelp.php?mysqlversion=...&keyword=...`

### 4.4 服务器变量编辑 (TfrmEditVariable)

#### 4.4.1 变量识别
- 从 `MySQLVariables` 常量数组查找变量定义
- 只读变量抛出异常
- 未找到变量抛出异常

#### 4.4.2 变量类型自动检测
| 类型 | 检测条件 | 编辑控件 |
|------|----------|----------|
| String | 默认 | editString |
| Numeric | 值为整数 | editNumber + UpDown |
| Boolean | 值为 ON/OFF/0/1/YES/NO | radioBooleanOn/Off |
| Enum | 值在 EnumValues 列表中 | comboEnum |

#### 4.4.3 作用域
- Session / Global 单选按钮
- 根据变量 VarScope 属性启用/禁用

#### 4.4.4 生成 SQL
- 语法: `SET @@session|global.var_name = value`
- 数值/布尔值: 直接写入（不加引号）
- 字符串: 数值格式的字符串不加引号（兼容 int64/float 变量）
- 枚举: 加引号
- 执行后保持对话框打开（错误时不关闭）

### 4.5 更新检查 (TfrmUpdateCheck)

#### 4.5.1 检查流程
1. 下载 INI 格式的更新文件: `{APPDOMAIN}updatecheck.php?r=revision&bits=64`
2. 解析 [Release] 段: 版本号 / 修订号 / 发布日期 / 备注
3. 解析 [Build] 段: 修订号 / 下载 URL / 编译日期 / 备注
4. 比较当前修订号判断是否有更新

#### 4.5.2 版本更新 (Release)
- 下载链接: installer / portable-64 / portable
- 便携模式额外显示更新说明
- 新版本优先于 nightly build

#### 4.5.3 构建更新 (Build)
- 仅 64 位版本支持
- 新版本发布时 build 按钮禁用（需先安装 release）
- 下载流程:
  1. 下载新 exe 到临时目录
  2. 提取内置的 updater 工具（资源 'UPDATER'）
  3. 创建 Windows 计划任务用于重启
  4. 调用 updater 替换 exe 并重启

#### 4.5.4 状态显示
- 下载中: 进度更新（200ms 节流）
- 已是最新: 显示 up-to-date
- 开发版本: 提示无法确定修订号

## 5. 业务规则与约束

### 5.1 表维护约束
- 仅 Table 和 View 可维护，其他类型跳过
- Checksum 需 MySQL 4.1.1+
- Check/Repair 选项按操作类型动态启用/禁用

### 5.2 导出约束
- 触发器必须在所有表之后导出（避免表不存在错误）
- 视图在第二遍再次导出（确保所有依赖表已创建）
- Insert size 控制每个 INSERT 语句的行数/大小
- ZIP 模式先写临时文件再压缩
- 导出到数据库时，目标数据库中不能选中同名对象

### 5.3 搜索约束
- SQL 模式下禁用大小写敏感和匹配类型选项
- 存储过程/函数搜索通过 information_schema 而非表数据
- 触发器和事件搜索标记为 TODO

### 5.4 数据库同步约束
- 当前仅检测缺失对象（Create），不支持 Alter/Insert 的差异检测
- Apply 功能未实现

### 5.5 变量编辑约束
- 只读变量不可编辑
- 数值字符串（int64/float 类型）不加引号以避免 "Incorrect argument type" 错误

## 7. 边界情况

### 7.1 表维护
- 表损坏时 CHECK/REPAIR 可能抛异常，记录到结果网格
- "Unknown database" 错误码 (1049) 触发强制取消

### 7.2 SQL 导出
- 文件创建失败 (EFCreateError) 或目录创建失败 (EInOutError) → 取消导出
- 导出到剪贴板: 使用 StreamToClipboard 在导出完成后执行
- 最近文件历史去重并持久化
- 服务器会话不作为默认输出选项持久化（避免意外连接）

### 7.3 全文搜索
- 大表搜索可能耗时较长
- SQLite 需切换 `PRAGMA case_sensitive_like`
- 无匹配列时显示 0 行 / 0% 而非跳过

### 7.4 更新检查
- 开发者版本 (revision=0) 无法比较
- 下载超时 5 秒
- Updater 工具 30 天内不重复提取
- Wine 环境显示弃用警告
- 32 位版本不支持 build 更新
- 应用目录不可写时要求管理员权限 (ElevationRequired)

### 7.5 SQL 帮助
- 帮助数据依赖 MySQL 的 HELP 系统表
- 分类名重复导致无限递归: 通过检查前序节点避免
- 窗口位置和大小持久化
