# ReidiSQL 新架构开发指南

> **重要说明**：本文档针对 ReidiSQL 重构项目（Tauri + React + Node.js 技术栈）。  
> 如需查看原 HeidiSQL（Delphi/VCL）的开发指南，请参阅 [开发指南.md](./开发指南.md)。

## 1. 项目概述

ReidiSQL 是 HeidiSQL 的现代化重构版本，采用跨平台技术栈实现：

- **应用框架**：Tauri 2.x（Rust 后端 + Web 前端）
- **前端技术**：React 18 + TypeScript + Vite
- **后端服务**：Node.js + TypeScript（数据库连接服务）
- **目标平台**：Windows、macOS、Linux

## 2. 开发环境设置

### 2.1 系统要求

#### 最低配置
- **CPU**：4 核心处理器
- **内存**：8 GB RAM
- **磁盘**：20 GB 可用空间
- **操作系统**：

## 4. 快速开始

### 4.1 克隆项目

```bash
git clone https://github.com/your-org/reidisql.git
cd reidisql
```

### 4.2 安装依赖

```bash
# 使用 npm
npm install

# 或使用 pnpm（推荐）
pnpm install
```

### 4.3 启动开发环境

```bash
# 方式1：一键启动（推荐）
npm run dev

# 方式2：分别启动
# 终端1：启动 Node.js 后端
npm run dev:backend

# 终端2：启动 Tauri 开发模式
npm run dev:tauri
```

### 4.4 运行测试

```bash
# 运行所有测试
npm test

# 运行前端测试
npm run test:frontend

# 运行后端测试
npm run test:backend

# 运行 E2E 测试
npm run test:e2e
```

### 4.5 构建生产版本

```bash
# 构建所有组件
npm run build

# 仅构建前端
npm run build:frontend

# 构建 Tauri 应用
npm run build:tauri
```

## 5. 开发工作流

### 5.1 代码规范

项目使用 ESLint + Prettier 确保代码质量：

```bash
# 检查代码规范
npm run lint

# 自动修复规范问题
npm run lint:fix

# 格式化代码
npm run format
```

### 5.2 提交前检查

项目使用 Husky + lint-staged 在提交前自动检查：

```bash
# 安装 Husky hooks
npm run prepare

# 提交代码时会自动运行：
# 1. ESLint 检查
# 2. Prettier 格式化
# 3. TypeScript 类型检查
# 4. 单元测试
```

### 5.3 Git 工作流

```bash
# 1. 创建功能分支
git checkout -b feature/your-feature-name

# 2. 开发并提交
git add .
git commit -m "feat: add new feature"

# 3. 推送到远程
git push origin feature/your-feature-name

# 4. 创建 Pull Request
```

**提交消息规范**（Conventional Commits）：
- `feat`: 新功能
- `fix`: 修复 bug
- `docs`: 文档更新
- `style`: 代码格式（不影响功能）
- `refactor`: 代码重构
- `test`: 测试相关
- `chore`: 构建过程或辅助工具变动

## 7. 常见问题

### Q1: Rust 编译失败

**解决方案**：
```bash
# 更新 Rust 工具链
rustup update

# 清理并重新编译
cd src-tauri
cargo clean
cargo build
```

### Q2: Node.js 驱动安装失败

**解决方案**：
```bash
# 安装构建工具
npm install -g node-gyp

# 清理缓存重新安装
npm cache clean --force
rm -rf node_modules
npm install
```

### Q3: Tauri 应用无法启动

**检查清单**：
- [ ] Node.js 后端服务是否运行
- [ ] 端口是否被占用
- [ ] 查看控制台错误日志
