# ReidiSQL 系统架构设计

## 1. 架构概述

ReidiSQL 采用经典的**分层架构**设计，将应用程序分为以下几个主要层次：

```
┌─────────────────────────────────────────┐
│         用户界面层 (UI Layer)            │
│  - 主窗体                                │
│  - 对话框和编辑器                        │
│  - 菜单和工具栏                          │
└─────────────────┬───────────────────────┘
                  │
┌─────────────────▼───────────────────────┐
│       业务逻辑层 (Business Logic Layer)  │
│  - 查询执行管理                          │
│  - 数据操作逻辑                          │
│  - 对象创建/删除/修改                    │
└─────────────────┬───────────────────────┘
                  │
┌─────────────────▼───────────────────────┐
│      数据访问层 (Data Access Layer)     │
│  - TDBConnection 抽象                    │
│  - 数据库特定实现 (MySQL/MSSQL等)       │
│  - 连接管理                              │
└─────────────────┬───────────────────────┘
                  │
┌─────────────────▼───────────────────────┐
│     基础设施层 (Infrastructure Layer)    │
│  - 数据库驱动 (FireDAC)                 │
│  - SynEdit 编辑器                        │
│  - VirtualTreeView 控件                  │
│  - 配置管理                              │
└─────────────────────────────────────────┘
```

## 2. 核心类层次结构

### 2.1 数据库连接类层次

```
TDbLib (基类)
  ├── 负责 DLL 加载和过程绑定
  └── 数据库特定的库实现

TSqlProvider
  ├── 提供 SQL 查询模板
  ├── 处理数据库特定的 SQL 差异
  └── 版本兼容性处理

TDBConnection (抽象基类)
  ├── TMySQLConnection
  ├── TMSSQLConnection
  ├── TPGSQLConnection
  ├── TSQLiteConnection
  ├── TInterbaseConnection
  └── TFirebirdConnection
```

### 2.2 数据库对象类层次

```
TPersistent
  ├── TTableColumn
  ├── TTableKey
  ├── TForeignKey
  ├── TCheckConstraint
  └── TDBObject
        ├── 代表数据库对象（表、视图、存储过程等）
        └── 包含对象元数据和操作方法
```

### 2.3 查询相关类层次

```
TDBQuery
  ├── 查询执行
  ├── 结果集管理
  └── 参数处理

TQueryThread
  └── 异步查询执行线程

TQueryTab
  ├── 查询标签页
  ├── 包含编辑器和结果展示
  └── 查询历史和状态管理

TQueryHistory
  └── 查询历史记录管理
```

## 3. 主要模块架构

### 3.1 主窗体架构 (MainForm)

```
TMainForm (主窗体)
  ├── 菜单栏
  ├── 工具栏
  ├── 左侧面板
  │   └── 数据库对象树 (TVirtualStringTree)
  ├── 中间面板
  │   ├── 查询标签页 (TTabSet)
  │   │   ├── SQL 编辑器 (TSynMemo)
  │   │   ├── 帮助面板 (treeHelpers)
  │   │   └── 结果面板
  │   │       └── 结果网格 (TVirtualStringTree)
  │   └── 数据/结构/选项等标签页
  └── 状态栏
```

### 3.2 对象树架构

对象树使用 VirtualTreeView 组件，采用延迟加载策略：

- 根节点：服务器连接
  - 数据库节点
    - 表节点
      - 列节点
      - 索引节点
    - 视图节点
    - 存储过程节点
    - 函数节点
    - 触发器节点
    - 事件节点

**节点状态标志**：
- `VTREE_NOTLOADED` = 0：未加载
- `VTREE_NOTLOADED_PURGECACHE` = 1：需要清除缓存重新加载
- `VTREE_LOADED` = 2：已加载

### 3.3 查询标签页架构

每个查询标签页（TQueryTab）包含：

1. **编辑器区域**
   - TSynMemo：SQL 编辑器
   - 语法高亮
   - 代码补全
   - 折叠功能

2. **帮助区域**
   - 列信息
   - 函数列表
   - 关键字
   - 代码片段
   - 查询历史
   - 查询分析
   - 参数绑定

3. **结果区域**
   - 多个结果标签页 (TResultTab)
   - 数据网格 (TVirtualStringTree)
   - 过滤功能

## 4. 数据流架构

### 4.1 查询执行流程

```
用户输入 SQL
    │
    ▼
TQueryTab 接收请求
    │
    ▼
创建 TQueryThread（异步执行）
    │
    ▼
TDBConnection 执行查询
    │
    ▼
FireDAC 访问数据库
    │
    ▼
返回结果集
    │
    ▼
解析结果 → 填充网格
    │
    ▼
显示结果 → 记录历史
```

### 4.2 数据编辑流程

```
用户修改网格数据
    │
    ▼
标记修改状态 (TEditingStatus)
    │
    ▼
用户提交更改
    │
    ▼
生成 SQL 语句 (INSERT/UPDATE/DELETE)
    │
    ▼
执行 SQL
    │
    ▼
刷新显示
```

### 4.3 对象树加载流程

```
用户展开节点
    │
    ▼
检查加载状态
    │
    ├── 已加载 → 显示子节点
    │
    └── 未加载
        │
        ▼
    查询数据库获取子对象
        │
        ▼
    创建 TDBObject 实例
        │
        ▼
    添加到树节点
        │
        ▼
    标记为已加载
```

## 5. 组件集成架构

### 5.1 SynEdit 集成

SynEdit 用于 SQL 编辑器，提供以下功能：

- **语法高亮**：使用 TSynSQLSyn
- **代码完成**：TSequelSuggest
- **查找替换**：内置的搜索功能
- **代码折叠**：按语句/块折叠
- **导出功能**：导出为 HTML/RTF

### 5.2 VirtualTreeView 集成

VirtualTreeView 用于两个主要区域：

1. **左侧对象树**：显示数据库对象层次
2. **结果网格**：显示查询结果和表数据

特性：
- 虚拟模式（Virtual Mode）：只渲染可见行
- 自定义绘制
- 支持排序、过滤
- 拖拽支持

### 5.3 FireDAC 集成

FireDAC 作为数据访问层，提供：

- 统一的数据库访问接口
- 连接池管理
- 参数化查询
- 事务支持
- 异步执行

## 6. 配置和持久化架构

### 6.1 配置存储

配置存储在 Windows 注册表中：

```
HKEY_CURRENT_USER\Software\HeidiSQL\
  ├── Servers\          # 连接配置
  ├── QueryHistory\     # 查询历史
  └── RecentFilters\    # 最近使用的过滤器
```

### 6.2 应用设置类 (TAppSettings)

负责读取和写入应用程序设置：

- 界面设置
- 连接配置
- 查询历史
- 用户偏好

## 7. 国际化架构

### 7.1 GNU Gettext 集成

使用 GNU Gettext 实现多语言支持：

- **翻译文件**：.po/.mo 文件
- **运行时切换**：支持动态切换语言
- **文本提取**：从源代码提取可翻译字符串

### 7.2 语言支持

- 多种语言翻译
- 语言检测和回退机制
- 翻译缓存

## 8. 错误处理架构

### 8.1 madExcept 集成

使用 madExcept 进行错误报告：

- 自动捕获异常
- 生成详细的错误报告
- 堆栈跟踪
- 崩溃转储

### 8.2 数据库错误处理

```pascal
EDbError = class(Exception)
  ErrorCode: Cardinal;  // 数据库错误代码
  Hint: String;         // 提示信息
end;
```

## 9. 性能优化策略

### 9.1 数据加载优化

- 延迟加载对象树
- 分页加载大结果集
- 大字段分段加载（GRIDMAXDATA = 256 字节）

### 9.2 缓存策略

- 列信息缓存 (TColumnCache)
- 索引信息缓存 (TKeyCache)
- 外键信息缓存 (TForeignKeyCache)

### 9.3 异步处理

- 查询异步执行 (TQueryThread)
- 防止界面阻塞
- 进度反馈

## 10. 扩展点架构

### 10.1 数据库支持扩展

通过继承 `TDBConnection` 和 `TSqlProvider` 添加新数据库支持：

1. 创建新的连接类继承 TDBConnection
2. 创建 SQL 提供者类继承 TSqlProvider
3. 在 dbstructures.xxx.pas 中定义数据类型
4. 注册到连接工厂

### 10.2 插件架构

预留插件扩展点，支持：

- 自定义数据导入导出
- 自定义编辑器功能
- 自定义报表生成
