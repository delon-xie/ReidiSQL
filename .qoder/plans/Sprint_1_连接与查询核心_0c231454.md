# Sprint 1: 连接 + 查询核心路径（已完成）

## 范围

基于迁移 PRD Sprint 1 定义，实现核心连接与查询功能：
1. 连接管理 — 后端 CRUD + JSON 持久化
2. 真实数据库连接 — mysql2/pg/better-sqlite3
3. SQL 查询执行 — 类型识别 + 历史记录
4. 元数据获取 — information_schema 完整查询
5. 前端三栏布局 — 对象树/SQL编辑器/结果网格/日志面板

## Task 1: 后端连接配置持久化 (B1)

**新建** `node-backend/src/services/configStore.ts` (146 行)
- 连接配置 JSON 持久化到 `~/.reidisql/connections.json`
- CRUD 方法：getAll/getById/create/update/delete/touchConnected

## Task 2: 后端真实连接服务 (B2)

**重写** `node-backend/src/services/connectionService.ts` (397 行)
- ConnectionManager 类管理真实数据库连接池
- 支持 MySQL/MariaDB（mysql2 Pool）、PostgreSQL（pg Pool）、SQLite（better-sqlite3）
- 方法：connect/disconnect/testConnection/getMySQLPool/getDatabases/shutdown

## Task 3: 后端查询执行服务 (B3)

**重写** `node-backend/src/services/queryService.ts` (179 行)
- SQL 执行 + mysqlTypeToString 类型映射 + 类型分类
- 查询历史管理（内存，最近 1000 条）

## Task 4: 后端元数据服务 (B4)

**重写** `node-backend/src/services/metadataService.ts` (281 行)
- information_schema 查询：库/表/列/索引/外键/视图/存储过程/触发器/事件
- 服务器信息/变量/进程列表

## Task 5: 后端路由 + WebSocket (B5)

**重写** 路由文件 + `index.ts` (125 行)
- `/api/connections` — CRUD + connect/disconnect/test
- `/api/queries` — execute/history
- `/api/metadata` — 16 个元数据端点
- WebSocket `/ws` — 实时日志推送

## Task 6: 前端 API 客户端 (F1)

**新建** `frontend/src/lib/api.ts` (131 行)
- Axios 封装 + 响应拦截器
- connectionsApi/queriesApi/metadataApi 全部端点

## Task 7: 前端 Zustand Stores (F2)

**新建** 4 个 Store：
- `connectionStore.ts` — 连接状态管理
- `queryStore.ts` — 查询多 Tab 管理

## Task 8: 前端组件 (F3-F8)
