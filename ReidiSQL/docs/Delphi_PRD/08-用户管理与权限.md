# PRD-08: 用户管理与权限

## 1. 功能概述

用户管理与权限模块提供 MySQL/MariaDB 用户和角色的完整管理功能，包括用户/角色的创建、删除、重命名，密码管理（含随机密码生成和强度检测），认证插件配置，多层级权限管理（全局/数据库/表/列/存储过程），角色分配，SSL 安全要求，以及资源限制。

| `usermanager.pas` | 1983 | TUserManagerForm / TUser / TPrivObj |
| `change_password.pas` | 180 | TfrmPasswordChange |
| `selectdbobject.pas` | 216 | TfrmSelectDBObject（PRD-07 已描述）|

## 4. 功能详细说明

### 4.1 用户管理器 (TUserManagerForm)

#### 4.1.1 用户列表
- **控件**: `listUsers` (TVirtualStringTree)
- 3 列: Username / Host / Plugin
- 图标: 用户图标 (ICONINDEX_USER) 或角色图标 (ICONINDEX_ROLE)
- 覆盖图标:
  - 空密码: 警告图标 (161)
  - 已修改未保存: 修改标记图标 (162)
- 问题用户（无效密码长度、skip-name-resolve 冲突）显示为禁用状态
- **过滤**: `editFilterUsers` 实时过滤用户节点
- **排序**: 点击列头排序

#### 4.1.2 用户问题检测
| 问题类型 | 条件 | 提示 |
|----------|------|------|
| upEmptyPassword | 密码为空 | "This user has an empty password." |
| upInvalidPasswordLen | 密码哈希长度不是 0/16/41 | "This user is inactive due to invalid password length..." |
| upSkipNameResolve | 主机名需要 DNS 解析但服务器启用了 skip-name-resolve | "This user is inactive due to having a host name..." |
| upUnknown | SHOW GRANTS 返回错误 | "This user is inactive due to some unknown reason." |

#### 4.1.3 添加用户
- 弹出菜单: 用户 / 角色 两个选项
- 新建用户:
  - 默认用户名: "Unnamed"
  - 默认主机: "localhost"
  - 空密码
- 新建角色:
  - 输入对话框填写角色名
  - 执行 `CREATE ROLE` SQL
  - 角色无 Host / Password / Limitations / SSL

#### 4.1.4 克隆用户
- 复制当前用户的所有 GRANT 语句到 FCloneGrants
- 新用户名与原名相同（需手动修改）
- 主机和密码与原用户相同
- 权限完全复制

#### 4.1.5 删除用户
- 新建未保存: 直接从列表移除
- 已有用户: 确认对话框
- 旧服务器 (<5.0.2): 先 REVOKE ALL，再删除
- 用户: `DROP USER 'user'@'host'`
- 角色: `DROP ROLE 'role'`
- 删除后执行 `FLUSH PRIVILEGES`

#### 4.1.6 Credentials 标签
**用户名与主机**:
- `editUsername`: 用户名
- `editFromHost`: 主机，带右键菜单:
  - 预设主机: localhost / 127.0.0.1 / % / ::1
  - 动态添加: 已有用户的主机列表（去重）
  - 选中时自动填入

**密码管理**:
- `editPassword` / `editRepeatPassword`: 密码输入，`*` 掩码
- 编辑后变为掩码模式
- 右键菜单: 插入随机密码（6/8/10/12/30 字符，各 20 个候选）
- 密码哈希（以 `*` 开头且长度 41）直接使用 `PASSWORD hash` 语法
- 普通密码使用 `IDENTIFIED BY 'password'`

**认证插件**:
- `comboPlugins`: 下拉列表，从服务器查询可用插件
- 第一项为 "None"
- MariaDB 使用 `VIA plugin USING password`，MySQL 使用 `WITH plugin BY password`

**默认角色**:
- `comboDefaultRole`: 列出所有可用角色 + "None"
- 需要服务器支持 is_role 列

#### 4.1.7 Limitations 标签（仅用户，角色不可用）
- `udMaxQueries`: MAX_QUERIES_PER_HOUR，默认 0（无限制）
- `udMaxUpdates`: MAX_UPDATES_PER_HOUR
- `udMaxConnections`: MAX_CONNECTIONS_PER_HOUR
- `udMaxUserConnections`: MAX_USER_CONNECTIONS（需 MySQL 5.0.3+）
- 每项带 UpDown 控件
- 修改检测: 比较当前值与用户原始值

#### 4.1.8 SSL 标签（仅用户）
- `comboSSL` 选项:
  - 0: None — `REQUIRE NONE`
  - 1: SSL — `REQUIRE SSL`
  - 2: X509 — `REQUIRE X509`
  - 3: Specified — `REQUIRE CIPHER '...' AND ISSUER '...' AND SUBJECT '...'`
- 选择 "Specified" 时启用:
  - `editCipher`: 加密算法
  - `editIssuer`: 证书颁发者
  - `editSubject`: 证书主题

#### 4.1.9 权限树 (Privileges)

**权限层级**:
| 层级 | NodeType | 可用权限 |
|------|----------|----------|
| 全局 (*.*) | lntNone | 所有权限（FILE, PROCESS, RELOAD, SHUTDOWN, SUPER, REPLICATION CLIENT/SLAVE, SHOW DATABASES, CREATE USER, CREATE TABLESPACE, 所有数据库级权限） |
| 数据库 (db.*) | lntDb | 数据库级（CREATE TEMPORARY TABLES, LOCK TABLES, CREATE ROUTINE, EVENT, TRIGGER, 所有表级权限） |
| 表 (db.table) | lntTable | ALTER, CREATE, DELETE, DROP, GRANT, INDEX, CREATE VIEW, SHOW VIEW, 列级权限 |
| 视图 (db.view) | lntView | 同表权限 |
| 存储过程 (db.proc) | lntProcedure | EXECUTE, ALTER ROUTINE, GRANT |
| 函数 (db.func) | lntFunction | EXECUTE, ALTER ROUTINE, GRANT |
| 列 (db.table.col) | lntColumn | INSERT, SELECT, UPDATE, REFERENCES |

**权限颜色编码**:
- 读权限 (PrivsRead): SELECT, SHOW VIEW, SHOW DATABASES, EXECUTE 等 — 特定颜色
- 写权限 (PrivsWrite): ALTER, CREATE, DELETE, DROP, INDEX, INSERT, UPDATE 等 — 特定颜色
- 管理权限 (PrivsAdmin): RELOAD, SHUTDOWN, SUPER, FILE, PROCESS, REPLICATION 等 — 特定颜色

**树形控件** (`treePrivs`):
- 第 0 级: 权限对象节点（全局/数据库/表等）
- 第 1 级: 具体权限复选框
- 三态复选框: 全选 / 部分选 / 不选
- 展开某节点时自动折叠其他同级节点
- 新增对象用叠加图标 (163) 标记

**添加权限对象**:
- 点击 "+" 按钮调用 SelectDBObjects 对话框
- 支持类型: Database / Table / View / Function / Procedure / Column
- 重复检查: 已有相同对象则报错
- 默认授予: 存储过程/函数 → EXECUTE, 其他 → SELECT

**权限解析**:
- 从 `SHOW GRANTS FOR user@host` 获取 GRANT 语句
- 正则表达式解析:
  ```
  ^GRANT\s+(.+)\s+ON\s+((TABLE|FUNCTION|PROCEDURE)\s+)?(\*|[`"]([^`"]+)[`"])\.(\*|[`"]([^`"]+)[`"])\s+TO\s+\S+...
  ```
- 处理: ALL PRIVILEGES / 列级权限 / USAGE
- WITH GRANT OPTION 单独解析

**MariaDB 特有权限**:
- 10.5.2+: BINLOG ADMIN, BINLOG REPLAY, CONNECTION ADMIN, FEDERATED ADMIN, READ_ONLY ADMIN, REPLICATION MASTER ADMIN, REPLICATION SLAVE ADMIN, SET USER（替代 REPLICATION CLIENT）
- 10.5.9+: SLAVE MONITOR
- 10.3.4+: DELETE HISTORY

#### 4.1.10 角色标签 (Roles)
- **控件**: `ValueListEditorRoles`
- 列出所有可用角色，值为: No / Yes / Yes, with admin option
- 需要服务器支持 `is_role` 列（MariaDB）
- 标签显示已分配角色数量

#### 4.1.11 保存逻辑 (btnSaveClick)
保存顺序:
1. **验证**: 用户名+主机唯一性 / 两次密码一致性
2. **CREATE USER**（新增用户, MySQL 5.0.2+）: 含密码和插件
3. **权限应用**: 遍历所有 PrivObj:
   - REVOKE 删除的权限
   - GRANT 新增的权限（含列级权限）
   - WITH GRANT OPTION
4. **全局选项**（仅全局权限对象）:
   - ALTER USER ... IDENTIFIED VIA/WITH plugin
   - ALTER USER ... REQUIRE ssl_clause
   - ALTER USER ... WITH MAX_QUERIES_PER_HOUR N MAX_UPDATES_PER_HOUR N ...
5. **SET PASSWORD**（修改密码，非新建或旧服务器）
6. **角色管理**: GRANT/REVOKE 角色
7. **默认角色**: SET DEFAULT ROLE
8. **重命名用户**: RENAME USER（5.0.2+）或 UPDATE mysql.user/db/tables_priv/columns_priv
9. **FLUSH PRIVILEGES**

#### 4.1.12 切换用户时的保存提示
- `listUsersFocusChanging`: 当 Modified 为 True 时弹出三选一:
  - Yes: 保存当前用户
  - No: 丢弃修改（新建用户则删除）
  - Cancel: 不切换

#### 4.1.13 窗口持久化
- 窗口大小: asUsermanagerWindowWidth / Height
- 左侧面板宽度: asUsermanagerListWidth
- 列配置: SaveListSetup

### 4.2 密码修改对话框 (TfrmPasswordChange)

#### 4.2.1 密码输入
- `editPassword` / `editRepeatPassword`: ButtonedEdit
- 空时显示明文，输入后自动切换为 `*` 掩码
- 按 Enter 键触发 Change 事件

#### 4.2.2 状态提示
- 空密码: "Please change your password"
- 不匹配: "Error: Passwords do not match!"
- 匹配: "Password strength:" + 强度条

#### 4.2.3 密码强度检测 (CheckPasswordStrength)
- 算法: 计算相邻字符 ASCII 码差值之和 + 长度×10
- 进度条显示:
  - 0-20%: 红色 (pbsError) — 弱
  - 21-50%: 黄色 (pbsPaused) — 中
  - 51-100%: 绿色 (pbsNormal) — 强

#### 4.2.4 随机密码生成
- 右键菜单分 5 组: 6/8/10/12/30 字符
- 每组展开生成 20 个候选密码
- 点击插入到密码框，同步到重复密码框

#### 4.2.5 复制到剪贴板
- `btnCopyToClipboard`: 复制密码到剪贴板
- 按钮图标短暂切换为 "已复制" 图标 (500ms)

#### 4.2.6 OK 按钮逻辑
- 密码非空 + 两次匹配 → 启用
- 否则禁用

## 5. 业务规则与约束

### 5.1 用户与角色的区别
| 特性 | 用户 | 角色 |
|------|------|------|
| Host | ✓ 必须 | ✗ 无 |
| 密码 | ✓ 可选 | ✗ 无 |
| 认证插件 | ✓ 可选 | ✗ 无 |
| 资源限制 | ✓ 可配置 | ✗ 无 |
| SSL 要求 | ✓ 可配置 | ✗ 无 |
| 默认角色 | ✓ 可设置 | ✗ 无 |
| 权限 | ✓ 可配置 | ✓ 可配置 |
| 创建语法 | CREATE USER | CREATE ROLE |
| 删除语法 | DROP USER | DROP ROLE |

### 5.2 密码处理
| 场景 | SQL 语法 |
|------|----------|
| 新建用户（明文密码） | `CREATE USER u IDENTIFIED BY 'pass'` |
| 新建用户（密码哈希） | `CREATE USER u IDENTIFIED BY PASSWORD '*hash'` |
| 新建用户（指定插件） | `CREATE USER u IDENTIFIED VIA plugin USING 'pass'` (MariaDB) / `WITH plugin BY 'pass'` (MySQL) |
| 修改密码（MySQL 5.7.6+） | `SET PASSWORD FOR u@h = 'pass'` |
| 修改密码（旧版/MariaDB） | `SET PASSWORD FOR u@h = PASSWORD('pass')` |

### 5.3 权限版本兼容
| 服务器版本 | 新增权限 |
|------------|----------|
| 4.0.2+ | REPLICATION CLIENT, REPLICATION SLAVE, SHOW DATABASES, SUPER, CREATE TEMPORARY TABLES, LOCK TABLES, EXECUTE |
| 5.0.1+ | CREATE VIEW, SHOW VIEW |
| 5.0.3+ | CREATE USER, CREATE ROUTINE, ALTER ROUTINE |
| 5.1.6+ | TRIGGER, EVENT |
| 5.4.4+ | CREATE TABLESPACE |
| MariaDB 10.5.2+ | BINLOG ADMIN, BINLOG REPLAY, CONNECTION ADMIN 等 |
| MariaDB 10.5.9+ | SLAVE MONITOR |
| MariaDB 10.3.4+ | DELETE HISTORY |

### 5.4 密码列兼容
| 列名 | 存在条件 | 查询方式 |
|------|----------|----------|
| password | MySQL < 5.7.6 | 直接读取 |
| authentication_string | MySQL 5.7.6+ / MariaDB | 直接读取 |
| 两者都有 | 过渡期 | `IF(LENGTH(password)>0, password, authentication_string)` |
| 两者都没有 | 异常 | 抛出 "No password hash column available" |

### 5.5 skip-name-resolve 检测
- 查询 `skip_name_resolve` 会话变量
- 启用时，非 IP/localhost/通配符的主机名用户标记为问题用户
- 正则: `^(localhost|[\d\.\/\:_]+|.*%.*|[\w\d_]{4}\:.*)$` 匹配不需要 DNS 解析的主机

## 7. 边界情况

### 7.1 用户管理
- SHOW GRANTS 失败（如 ER_NONEXISTING_GRANT）: 禁用该用户节点，建议关闭 skip-name-resolve
- 旧服务器（<5.0.2）不支持 CREATE USER / RENAME USER: 回退到直接操作 mysql 系统表
- 重命名时: 旧服务器需 UPDATE mysql.user, db, tables_priv, columns_priv 四张表
- 角色重命名: 标记为 TODO，尚未实现

### 7.2 权限
- 列级权限解析: 从 `SELECT (col1, col2)` 中提取列名，创建独立的 lntColumn PrivObj
- ALL PRIVILEGES 自动展开为该层级所有可用权限（不含 GRANT）
- GRANT OPTION 单独追踪，作为 AddedPrivs/DeletedPrivs 中的 "GRANT" 条目
- USAGE 权限: 无任何实际权限时 GRANT 生成 USAGE

### 7.3 SSL
- REQUIRE 子句解析: 支持 SSL / X509 / CIPHER+ISSUER+SUBJECT 组合
- 有 CIPHER/ISSUER/SUBJECT 任一非空时自动设为 Specified 模式（SSL=3）

### 7.4 密码对话框
- 密码强度算法为简单启发式，非密码学安全
- 复制到剪贴板使用 Sleep(500ms) 实现视觉反馈，期间 UI 短暂冻结
- 随机密码每次展开菜单时重新生成 20 个候选

### 7.5 服务器兼容性
- `is_role` 列: 仅 MariaDB 支持，控制角色标签可见性和角色菜单启用
- `default_role` 列: 仅 MariaDB 支持
- `plugin` 列: 控制认证插件下拉可用性
- MySQL 5.7.6+: SHOW GRANTS 不再包含 IDENTIFIED BY PASSWORD 子句，改用 SHOW CREATE USER
