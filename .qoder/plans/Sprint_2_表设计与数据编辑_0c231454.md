# Sprint 2: 表设计 + 数据编辑

## 范围

基于迁移 PRD Sprint 2 定义，共 4 个交付模块：
1. 表设计器（TableEditor）— 可视化创建/修改表结构
2. 列/索引/外键编辑器 — 子组件 + ALTER TABLE 生成
3. 网格内联编辑 — AG Grid 行内编辑 + 数据修改 API
4. 数据导出 — ExportDialog + 多格式导出 API

## Task 1: 后端 DDL 服务（表结构操作）

**新建** `node-backend/src/services/ddlService.ts` (~200 行)

- `generateCreateTable(request)` — 从 ColumnDDL/IndexDDL/ForeignKeyDDL 生成 CREATE TABLE SQL
- `generateAlterTable(request)` — 生成 ALTER TABLE（ADD/MODIFY/DROP COLUMN, ADD/DROP INDEX）
- `executeDDL(connectionId, sql)` — 执行 DDL 语句
- 接口复用 `shared/types.ts` 中已定义的 `TableDDLRequest`、`ColumnDDL`、`IndexDDL`、`ForeignKeyDDL`

**新建** `node-backend/src/routes/ddl.ts` (~60 行)

- `POST /api/ddl/execute` — 执行任意 DDL
- `POST /api/ddl/table` — 从 TableDDLRequest 生成并执行建表/改表

## Task 2: 后端数据修改服务

**新建** `node-backend/src/services/dataService.ts` (~150 行)

- `insertRow(connectionId, database, table, data)` — INSERT
- `updateRow(connectionId, database, table, data, where)` — UPDATE
- `deleteRow(connectionId, database, table, where)` — DELETE
- `batchModify(connectionId, operations)` — 批量操作（事务内）

**新建** `node-backend/src/routes/data.ts` (~50 行)

- `POST /api/data/insert`
- `PUT /api/data/update`
- `DELETE /api/data/delete`
- `POST /api/data/batch` — 批量修改（事务）

**修改** `node-backend/src/index.ts` — 注册新路由

## Task 3: 后端导出服务

**新建** `node-backend/src/services/exportService.ts` (~200 行)

- `exportToCSV(connectionId, database, table, options)` — CSV 格式
- `exportToJSON(connectionId, database, table, options)` — JSON 格式
- `exportToSQL(connectionId, database, table, options)` — INSERT SQL 格式

**新建** `node-backend/src/routes/export.ts` (~40 行)

- `POST /api/export` — 统一导出接口
- 返回文件流或 JSON（小数据量时）

## Task 5: 前端表设计器

**新建** `frontend/src/components/TableEditor.tsx` (~300 行)

- 顶部：表名、引擎、字符集、排序规则
- Tabs：列 / 索引 / 外键 / 选项
- 列编辑器：AG Grid 内联编辑（name, type, length, nullable, default, auto_increment, comment）
- 索引编辑器：AG Grid 编辑（name, type, columns）
- 底部按钮：预览 SQL / 执行 / 取消
- 预览 SQL 弹窗：显示生成的 DDL

**新建** `frontend/src/stores/tableEditorStore.ts` (~100 行)

- 管理编辑中的表结构状态（columns, indexes, foreignKeys, options）
- 新建 vs 编辑模式区分
