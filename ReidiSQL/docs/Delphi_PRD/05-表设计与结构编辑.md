# PRD-05: 表设计与结构编辑

## 1. 功能概述

表设计与结构编辑模块提供可视化的表结构管理界面，支持创建新表和修改现有表结构。用户可通过网格编辑器管理列定义（名称、数据类型、长度、属性、默认值、注释等）、索引/键管理（PRIMARY KEY/UNIQUE/INDEX/FULLTEXT/SPATIAL）、外键约束、CHECK 约束、表选项（引擎/排序规则/行格式等），并实时预览生成的 CREATE/ALTER SQL 代码。

### 1.1 相关源码

| 文件 | 大小 | 职责 |
|------|------|------|
| `table_editor.pas` | 115KB | 表编辑器核心逻辑（列/索引/外键/选项/SQL 生成） |
| `table_editor.dfm` | 1078行 | 表编辑器 UI 布局定义 |
| `grideditlinks.pas` | 59KB | 网格编辑器（默认值编辑器、数据类型编辑器等） |
| `column_selection.pas` | 8KB | 列选择对话框（复用） |

## 4. 功能详细说明

### 4.1 列编辑

#### 4.1.1 列属性

| 列属性 | 列号 | 类型 | 说明 |
|--------|------|------|------|
| # | 0 | 序号 | 只读，列的物理顺序 |
| Name | 1 | 文本 | 列名，最大长度 `NAME_LEN` |
| Datatype | 2 | 下拉 | 数据类型，使用 `TDataTypeEditorLink` 树形选择器 |
| Length/Set | 3 | 文本 | 长度或集合值（如 `VARCHAR(255)`, `ENUM('a','b')`） |
| Unsigned | 4 | 复选框 | 无符号标记（仅数值类型） |
| Allow null | 5 | 复选框 | 是否允许 NULL |
| Zerofill | 6 | 复选框 | 零填充标记 |
| Default | 7 | 编辑器 | 默认值，使用 `TColumnDefaultEditorLink`（无/文本/NULL/表达式/自增） |
| Comment | 8 | 文本 | 列注释 |
| Collation | 9 | 下拉 | 列级排序规则 |
| Expression | 10 | 文本 | 虚拟列表达式（MariaDB 专属） |
| Virtuality | 11 | 下拉 | 虚拟列类型：STORED/VIRTUAL（MariaDB 专属） |
| SRID | 12 | 文本 | 空间参考标识符 |
| Invisible | 13 | 复选框 | 不可见列标记 |
| Compressed | 14 | 复选框 | 压缩列标记（MariaDB 专属） |

#### 4.1.2 列操作

| 操作 | 说明 |
|------|------|
| 添加列 | 在选中列后插入新列；复制选中列的类型/长度/Unsigned/AllowNull 属性；默认列名为 "Column N" |
| 删除列 | 标记为 `esDeleted`，不立即物理删除，保存时生成 DROP COLUMN 语句 |
| 上移/下移 | 交换列的物理位置（通过 `FColumns.Exchange` 实现） |
| 拖拽排序 | 支持拖拽列节点到新位置，使用 `DragDrop` 事件 |
| 复制列 | 复制选中列的完整定义到内部剪贴板 |
| 粘贴列 | 在当前位置粘贴已复制的列定义 |
| 从列创建索引 | 右键菜单快捷操作：为选中列创建新 INDEX/UNIQUE/FULLTEXT/SPATIAL 索引 |
| 添加到索引 | 右键菜单：将选中列添加到现有索引 |

#### 4.1.3 数据类型编辑器 (TDataTypeEditorLink)

- 树形选择器展示所有数据类型，按类别分组（Integer、Real、Text、Binary、Temporal、Spatial、Other）
- 选中类型后显示帮助说明（`TMemo`）
- 类型列表来自数据库连接（`Conn.Datatypes`）

#### 4.1.4 默认值编辑器 (TColumnDefaultEditorLink)

- 单选组选择默认值类型：
  - **Nothing**：无默认值
  - **Text**：文本值（带下拉选择）
  - **NULL**：NULL 值
  - **Expression**：SQL 表达式（带下拉选择常用函数如 `CURRENT_TIMESTAMP`）
  - **Auto increment**：自增标记
- ON UPDATE 表达式编辑器（MySQL 专属，如 `CURRENT_TIMESTAMP`）

### 4.2 索引管理

#### 4.2.1 索引树结构

索引采用两级树形结构：
- **第一级**：索引定义（Name/Type/Algorithm/Comment/Direction/Visibility）
- **第二级**：索引列（从列列表拖入或手动添加）

#### 4.2.2 索引类型

| 类型 | 说明 |
|------|------|
| PRIMARY KEY | 主键索引（每表最多一个） |
| INDEX | 普通索引 |
| UNIQUE | 唯一索引 |
| FULLTEXT | 全文索引（MyISAM/InnoDB） |
| SPATIAL | 空间索引（MyISAM/InnoDB） |

#### 4.2.3 索引操作

| 操作 | 说明 |
|------|------|
| 添加索引 | 创建空索引节点，需手动添加列或从列列表拖入 |
| 删除索引 | 移入 `FDeletedKeys` 列表，保存时生成 DROP INDEX 语句 |
| 清空索引 | 删除所有索引 |
| 上移/下移 | 调整索引定义中列的顺序 |
| 拖拽添加列 | 从列列表拖拽列名到索引节点上，自动添加为索引列 |
| 列长度设置 | 索引列支持指定前缀长度（如 `name(50)`） |
| 方向设置 | ASC/DESC 排序方向 |
| 可见性 | 可见/不可见（MySQL 8.0+ / MariaDB 10.6+） |
| 算法 | BTREE/HASH/RTREE 等 |

#### 4.2.4 保存验证

保存前检查所有索引是否至少包含一列，若存在空索引则弹出错误提示并中止保存。

### 4.3 外键管理

#### 4.3.1 外键属性

| 属性 | 说明 |
|------|------|
| Name | 外键约束名称 |
| Reference table | 引用的目标表（数据库.表名） |
| Columns | 本表的列（可多选） |
| Foreign key columns | 引用表的对应列 |
| ON UPDATE | 更新时行为：RESTRICT/CASCADE/SET NULL/NO ACTION/SET DEFAULT |
| ON DELETE | 删除时行为：RESTRICT/CASCADE/SET NULL/NO ACTION/SET DEFAULT |

#### 4.3.2 反向外键

- 显示引用当前表的其他表外键列表
- 通过工具栏按钮 `btnShowReverseForeignKeys` 切换显示/隐藏
- 列表包含：数据库名、表名、约束名
- 双击条目可跳转到引用表的编辑器
- 显示状态保存在 `asDisplayReverseForeignKeys`

#### 4.3.3 特殊处理

- 修改外键时先生成 DROP 语句，再生成 ADD 语句（MySQL 不允许在单条 ALTER TABLE 中同时 DROP 和 ADD 外键）
- InnoDB 约束错误时自动获取 `SHOW ENGINE INNODB STATUS` 提供详细错误信息

### 4.4 CHECK 约束

| 属性 | 说明 |
|------|------|
| Name | 约束名称 |
| Check clause | CHECK 表达式 |
| Enforced | 是否强制（MySQL 8.0.16+） |

- 添加/删除/清空操作
- 行内编辑约束名和表达式

### 4.5 表选项 (Options)

| 选项 | 控件类型 | 说明 |
|------|----------|------|
| Auto increment | 数值输入 | 自增值起始值 |
| Average row length | 数值输入 | 平均行长度（字节） |
| Maximum row count | 数值输入 | 最大行数 |
| Checksum | 复选框 | 行校验和 |
| Row format | 下拉框 | DEFAULT/DYNAMIC/FIXED/COMPRESSED/REDUNDANT/COMPACT |
| INSERT method | 下拉框 | NO/FIRST/LAST（MERGE 表专用） |
| Default collation | 下拉框 | 表默认排序规则，来自 `Connection.CollationList` |
| Engine | 下拉框 | 存储引擎，来自 `Connection.TableEngines`，首项为 "Server default" |
| Union tables | 多行文本 | MERGE 表的联合表列表 |
| Convert data | 复选框 | 更改排序规则时是否转换现有数据 |

**引擎联动**：选择不同引擎时，自动启用/禁用相关选项（如 UNION/INSERT method 仅对 MERGE 引擎可用）

**字符集转换**：
- 勾选 "Convert data" 后，生成 `CONVERT TO CHARSET ... COLLATE ...` 语句
- 自动调整所有列的排序规则为新表默认排序规则
- 保存后自动取消勾选，防止重复转换

### 4.6 分区 (Partitions)

- 以 SynMemo 编辑器显示原始分区定义 SQL
- 从 `SHOW CREATE TABLE` 中提取 `PARTITION BY ...` 部分
- 新建表时为空
- 保存时附加到 CREATE TABLE 语句末尾（MySQL 条件注释格式 `/*!50100 ... */`）

### 4.7 SQL 代码预览

#### 4.7.1 CREATE 代码标签页

- 实时显示 `CREATE TABLE` 语句
- 包含列定义、索引、外键、CHECK 约束、表选项
- PostgreSQL 额外生成 `COMMENT ON TABLE/COLUMN` 语句
- 非 `InsideCreateCode` 的索引单独生成 `CREATE INDEX` 语句

#### 4.7.2 ALTER 代码标签页

- 仅在编辑现有表时显示
- 智能生成增量 ALTER TABLE 语句：
  1. 先 DROP 修改的外键（单独语句，避免 MySQL 错误 121）
  2. DROP DEFAULT（当列从有默认值改为无默认值时）
  3. 表选项变更（COMMENT/COLLATE/ENGINE/ROW_FORMAT 等）
  4. 列变更（ADD/MODIFY/CHANGE COLUMN）
  5. 删除列（DROP COLUMN）
  6. 索引变更（DROP + ADD INDEX）
  7. 外键变更（ADD FOREIGN KEY）
  8. CHECK 约束变更
  9. 索引可见性变更（单独 ALTER INDEX 语句）
- 多数据库方言支持：MySQL/MSSQL/PostgreSQL/SQLite 各有不同的 ALTER 语法

### 4.8 保存逻辑 (ApplyModifications)

**执行流程**：
1. 验证所有索引至少包含一列
2. 根据 `ObjectExists` 判断生成 CREATE 或 ALTER 语句
3. 逐条执行 SQL 语句，显示警告
4. 若表名变更，执行 RENAME TABLE
5. 刷新数据库对象树和查询助手
6. 重置修改标志
7. 异常处理：捕获 `EDbError`，对 InnoDB 外键错误提供 INNODB STATUS 详情

### 4.9 放弃修改 (Discard)

- 调用 `Init(DBObject)` 重新初始化编辑器
- 丢弃所有未保存的变更

### 4.10 修改检测

- 所有输入控件的 `OnChange` 事件触发 `Modification` 方法
- 设置 `Modified := True`，启用保存/放弃按钮
- 保存按钮仅当表名非空且至少有一列时启用
- 代码预览标签页内容在修改时标记为无效，切换时重新生成

## 5. 业务规则与约束

| ID | 规则 | 说明 |
|----|------|------|
| BR-5.1 | 表名必填 | 表名不能为空，最大长度 `NAME_LEN` |
| BR-5.2 | 至少一列 | 表必须至少包含一个列定义 |
| BR-5.3 | 索引非空验证 | 保存前检查所有索引至少包含一个列 |
| BR-5.4 | 唯一自增列 | 一张表只能有一个 AUTO_INCREMENT 列 |
| BR-5.5 | 外键单独 DROP | 修改外键时先单独 DROP 再 ADD，避免 MySQL Error 121 |
| BR-5.6 | 默认排序值移除 | 列从有默认值改为无默认值时，需单独 ALTER ... DROP DEFAULT |
| BR-5.7 | 引擎版本兼容 | MySQL < 4.0.18 使用 `TYPE=` 代替 `ENGINE=` |
| BR-5.8 | 注释长度限制 | MySQL < 5.5.3 注释最大 60 字符，之后为 2048 字符 |
| BR-5.9 | 列位置 | MySQL 4.0.1+ 支持 `FIRST`/`AFTER` 子句指定列位置 |
| BR-5.10 | PostgreSQL 列修改 | PostgreSQL 列修改拆分为多条 ALTER COLUMN（TYPE/NULL/DEFAULT/COLLATION） |
| BR-5.11 | SQLite 限制 | SQLite 仅支持重命名列和添加列，不支持修改列属性 |
| BR-5.12 | MariaDB 专属列 | Expression/Virtuality/Compressed 列仅在 MariaDB 连接时显示 |

## 7. 边界情况

| 场景 | 处理方式 |
|------|----------|
| 新建表无列 | 保存按钮禁用，提示至少添加一列 |
| 空索引（无列） | 保存时弹出错误对话框，中止保存 |
| 删除已存在的列 | 标记为 `esDeleted`，保存时生成 DROP COLUMN |
| 添加列后又删除 | 状态设为 `esAddedDeleted`，从列表中完全移除，不生成任何 SQL |
| InnoDB 外键错误 | 自动获取 INNODB STATUS 并显示详细约束失败信息 |
| 表名重复 | 依赖数据库服务器返回错误并显示 |
| 字符集转换 | 勾选后自动调整所有列排序规则，保存后自动取消勾选 |
| 保存成功 | 重新调用 `Init` 以服务器最新数据刷新编辑器 |
| 保存失败 | 保持编辑器打开，重新启用保存按钮 |
| 切换表 | 如有未保存修改弹出确认对话框 |
